PCB 接地设计与层叠结构学习笔记

Created2026-05-31|Updated2026-05-31|LearningCircuitHardware
|Word Count:1.4k|Reading Time:4mins|Post Views:

一、接地方式概述

PCB 接地是电磁兼容（EMC）设计的关键环节。常见的接地方式有三种：

接地方式 适用场景 特点
单点接地 低频模拟电路 所有模块地线接到公共点
多点接地 高频数字电路 各模块直接连接到最近的地平面
混合接地 数模混合电路 单点接地与多点接地的组合

1.1 单点接地（星形接地）

单点接地是将所有模块电路的地线都接到公共模块的一点，通常连接到电源地（如电池负极）。

串联单点接地

优点 缺点
结构简单，布线方便 各模块电路存在耦合，会互相干扰

问题分析：由于共用接地路径，会产生串扰（Crosstalk），不适合对噪声敏感的电路。

并联单点接地

优点 缺点
解决了串扰问题 地线数量过多，布线复杂

1.2 多点接地

多点接地是将所有模块直接连接到距离最近的地平面。

特点：

  • 只有一种接地方式
  • 适用于工作频率较高的纯数字电路
  • 通常采用大面积覆铜实现

原理分析：

地线阻抗公式：
$$
Z = \omega L = 2\pi f L
$$

其中：

  • $f$ 为信号频率
  • $L$ 为走线电感

关键结论：走线过长会导致感抗过高，增大电磁干扰（EMI）。因此地线要尽可能短，以减小阻抗。

优点：

  • 提高电磁兼容性（减轻信号干扰）
  • 布线简单，直接铺铜即可

缺点：

  • 不适合低频模拟电路

1.3 混合接地

混合接地是单点接地与多点接地的组合方案，适用于数模混合电路。

为什么需要混合接地？

电路类型 特点 接地要求
数字电路 频率高、变化快、噪声大 不一定要非常干净的地
模拟电路 频率低、信号微弱 需要非常干净的地

设计方案选择

场景 推荐方案
一块模拟电路 + 一块数字电路 并联单点接地
多块模拟电路 + 多块数字电路 混合接地
纯数字电路（高频） 多点接地

实践技巧：对于简单电路或高频数字电路，可以在混合接地基础上通过过孔进行铺铜，兼顾性能与布线便利性。

二、四层板层叠设计

2.1 四层板结构

四层板相当于”两层半”设计：

  • L2、L3：中间信号层，相当于两层板
  • L1、L4：顶层和底层，主要用于走线和元器件放置

优势：相比双层板，四层板提供了更多的走线空间和更完整的参考平面。

2.2 典型层叠方案

方案说明：

  • GND1：地平面合称，包括 AGND（模拟地）和 DGND（数字地）
  • PWR1：电源平面
  • 顶层和底层通过过孔连接到中间层，只需走信号即可

2.3 层叠设计原则

原则 说明
信号层要有好的参考层 GND 作为参考层比 PWR 更好
电源和地要耦合 减小电源平面阻抗
关键信号层要和地相邻 方便阻抗控制
信号层之间尽量避免相邻 减少串扰（非绝对）
相邻层信号不要平行布线 增加信号隔离

阻抗计算：对于传输线，必要时应使用仿真软件（如 Polar SI9000）进行微带线模型或带状线模型分析。

三、割地设计（数字地与模拟地分割）

3.1 为什么要割地？

问题根源：

  1. 数字信号电平幅度变化快、频率高
  2. 数字电路快速变化的电流会产生高频变化磁场
  3. 如果数字电路与模拟电路的接地线存在阻抗，或共用了存在阻抗的地线，就会干扰模拟电路

📺 推荐视频：“你割了吗？”数字地和模拟地到底要不要分割？

3.2 割地方法

方法一：完全分离

将数字地和模拟地分割成两种状态，两者在物理上完全分离，电源部分也分为数字电源和模拟电源两部分。两部分通过光耦或隔离变压器进行信号隔离。

优点 缺点
隔离效果好 成本高，设计复杂

方法二：单点连接（推荐）

使用一块完整地平面，切分为模拟地和数字地，两者在某处存在一小块连接区域。

✅ 更常见的方案，成本低且能满足大多数应用需求。

3.3 两地连接方式

连接元件 作用
磁珠 吸收抑制高频噪声和尖峰干扰
电容 提供高频通路，隔离低频
电感 隔离高频噪声
0Ω电阻 单点连接，便于调试
一小块铜箔 直接连接，成本最低

四、板载天线布局

布局原则：

  1. 优先位置：板角（corner）
  2. 次选位置：板边（edge）

原因：板角和板边可以减少 PCB 铜箔对天线辐射方向图的影响，提高天线效率。

五、总结

设计要点 关键结论
接地方式选择 低频用单点，高频用多点，数模混合用混合
四层板设计 信号层相邻地平面，电源地要耦合
割地设计 推荐单点连接方案，连接元件可选磁珠/0Ω电阻等
天线布局 优先板角，次选板边
