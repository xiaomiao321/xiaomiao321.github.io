分为有源元件和无源元件

有源元件需要外部供电才能工作，能对信号进行放大（输出能量>输入能量，把电源能量转化成信号能量了），如三极管、MOS、运放

📘 电子元器件基础 - 第三课：电阻器深度解析笔记

1. 关键参数（上）：阻值 & 功率

核心公式：

  • $P = I^2R = V^2/R = V \times I$ （功率计算是选型第一步）

安全裕量原则：

  • 实际功率 $\le$ 额定功率 $\times 50%$ （降额使用，延长寿命）

阻值标称系列 (E系列)：

系列 精度 常用阻值数量 典型应用
E6 ±20% 6个/十倍频程 粗略限流
E12 ±10% 12个/十倍频程 一般电路
E24 ±5% 24个/十倍频程 通用场合（最常见）
E48 ±2% 48个/十倍频程 精密仪器
E96 ±1% 96个/十倍频程 高精度设计
E192 ±0.5% 192个/十倍频程 顶级精密

常见功率规格：

  • 1/16 W, 1/10 W
  • 1/8 W, 1/4 W
  • 1/2 W, 1 W
  • 2 W, 5 W+

2. 关键参数（下）：精度 & 温度系数

精度等级代码：

代码 容差 典型应用
B ±0.1% 精密仪器/基准
C ±0.25% 高精度模拟
D ±0.5% 精密测量
F ±1% 通用高精度（推荐）
G ±2% 一般精度
J ±5% 大多数数字电路
K ±10% 粗略限流/滤波
M ±20% 容限宽松场合

温度系数 (TCR)：

  • 计算公式： $TCR = (R_2 - R_1) / [R_1 \times (T_2 - T_1)] \times 10^6$ (ppm/°C)

不同类型电阻的TCR及应用：

类型 典型TCR 应用场合
精密金属膜 ±25 ppm/°C 精密仪器-基准电路
普通金属膜 ±100 ppm/°C 通用高精度
碳膜 ±500 ppm/°C 一般消费电路
厚膜贴片 ±100~200 ppm/°C SMD通用
绕线 ±10~50 ppm/°C 大功率精密

⚠️ 注意： 高温环境下阻值会偏移！设计时需计算最坏情况：$R_{max} = R_0 \times (1 + TCR \times \Delta T)$

4. 三大应用电路

分压 · 限流 · 上下拉 —— 工程师必背公式

① 分压电路

  • 公式： $V_{out} = V_{in} \times R_2 / (R_1 + R_2)$
  • 示例： 5V转3.3V: $R_1=1.7k\Omega, R_2=3.3k\Omega$ (实际选 E24 标称值)
  • 要点：
    • $R_2 \le 1/10$ 负载阻抗，减少负载效应。
    • 精度要求高时用 E96 系列 ±1%。
    • ADC 采样前分压：注意输出阻抗影响。
    • 上下臂选相同温度系数，漂移自消。

② 限流电路

  • 公式： $R = (V_{cc} - V_f) / I_f$
  • 示例： 3.3V 驱动 LED: $R=(3.3-2.0)/0.01 = 130\Omega \rightarrow$ 取 $150\Omega$
  • 要点：
    • LED 限流：$V_f \approx 2V, I_f=10mA \rightarrow R=(5-2)/0.01=300\Omega$。
    • 实际取 E24 标称：$330\Omega$ (安全)。
    • 功率验算：$P = I^2 \times R = (0.01)^2 \times 330 = 33mW < 1/16W$ (√)。
    • 大电流时别忘降额50%。

③ 上下拉电路

  • 定义：
    • 上拉：悬空引脚确保高电平（默认 HIGH），接 $V_{cc}$。
    • 下拉：悬空引脚确保低电平（默认 LOW），接 GND。
  • 典型值：
    • I²C 上拉 2.2~10kΩ（速率决定）。
    • 按键下拉：10kΩ（防漏电，降功耗）。

5. 电阻选型五步法

系统选型，不再凭感觉：

  1. 确认应用场景
    • 限流/分压/上下拉/滤波？
    • 决定电阻类型（碳膜/金属膜/贴片）。
  2. 计算功率需求
    • $P = I^2R$ 或 $P = V^2/R$。
    • 额定功率 $\ge$ 实际功率 $\times 2$ （降额50%）。
  3. 确定精度等级
    • 数字电路：±5% (J级) 够用。
    • 模拟/ADC：±1% (F级)。
    • 基准：±0.1% (B级)。
  4. 选封装尺寸
    • 焊接能力 + 板面积 + 功率综合考虑。
    • 推荐：0603（平衡），1206（大功率手焊）。
  5. 验货源与替代料
    • LCSC/立创商城查库存。
    • 确认温度系数 & 品牌一致性。
    • 准备1~2个替代料型号。

6. 常见误区 & 避坑指南

这些错误，老工程师都踩过：

  • ❌ 功率只算额定，不降额
    • ✅ 正解： 实际功率 $\le$ 额定 $\times 50%$，高温再打折。
  • ❌ 分压忽略负载效应
    • ✅ 正解： $R_{load} \ge 10 \times R_2$，否则 $V_{out}$ 偏低。
  • ❌ I²C 上拉随意选 10kΩ
    • ✅ 正解： 400kHz用 $\le 2.2k\Omega$，100kHz可 $4.7k\Omega$。
  • ❌ 精密电路用碳膜电阻
    • ✅ 正解： 精度需求 > ±2% 必用金属膜或精密厚膜。
  • ❌ 不考虑温度系数漂移
    • ✅ 正解： 高温环境用低TCR电阻，计算漂移量。
  • ❌ 手随便抓一个电阻用
    • ✅ 正解： 看标称色环/印字，确认阻值再焊。

📘 电子元器件基础 - 第四课：特殊电阻器应用笔记

1. NTC 热敏电阻

核心特性：

  • 负温度系数 —— 温度升高，阻值下降。

  • 计算公式：

    $R(T) = R_0 \times \exp[B \times (1/T - 1/T_0)]$

    • $T$ 单位：开尔文 K
    • $T_0$ 通常 = 298.15K (25°C)
    • B值越大，灵敏度越高

关键参数：

参数 说明 典型值
$R_{25}$ 25°C标称阻值 1kΩ / 10kΩ / 100kΩ
B值 材料常数（灵敏度） 3380K / 3950K / 4250K
精度 阻值误差 ±1% / ±2% / ±5%
测量范围 有效温度范围 -55°C ~ +150°C

主要应用场景：

  1. 温度检测：分压 → ADC → MCU查表（或计算B值方程）。
  2. 电池保护：超温触发保护切断充/放电。
  3. 浪涌抑制：冷态高阻限流 → 热态低阻 → 开机浪涌抑制。

2. PTC / PPTC —— 自恢复保险丝

工作原理：

  • 正常工作 → 低阻态 ($m\Omega$) → 电流通过。
  • 过流触发 → 高温 → 阻值暴增 → 限制电流 → 自动保护。
  • 特点：过流保护，断电后自动恢复。

关键参数速查与选型原则：

参数 含义 选型原则
Ihold 保持电流（不动作） $\ge 1.1 \times$ 正常工作电流
Itrip 动作电流（触发保护） $\le 0.8 \times$ 最小故障电流
Vmax 最大工作电压 $\ge$ 电路最高电压 + 裕量
Imax 最大冲击电流 $\ge$ 预计最大短路电流
Rmin / Rmax 常温初始阻值范围 越小串联压降越小

典型应用：

  • USB口 (Ihold=500mA~1A)
  • 锂电保护板
  • 5V电源 (Ihold按负载电流×1.5)

3. MOV 压敏电阻 —— 瞬态过压保护

工作原理：

  • 氧化锌压敏电阻，双向对称 V-I 特性。
  • 正常电压 → 高阻态 ($\mu A$泄漏)。
  • 过压 → 瞬间低阻（泄放能量到地）。
  • 撤压 → 恢复高阻。

关键选型参数 (以220VAC系统为例)：

参数 含义 220VAC系统选型参考
Varistor Voltage $V_{1mA}$ 标称电压 (1mA时) $\ge 275V \times 1.2 \times \sqrt{2} \approx 470V \rightarrow$ 选500V型
Clamping Voltage $V_c$ 峰值钳位电压 $\le$ 后级耐压，典型$V_{1mA}$的2~2.5倍
Vac (Max) 最大持续交流电压 220VAC系统选$\ge 275VAC$型号
Energy (J) 单次可吸收能量 按雷击标准留2倍裕量
Peak Current $I_{peak}$ 最大冲击电流(8/20μs) $\ge$ 预计最大浪涌电流

AC入口三级防护架构： L/N线 → [MOV 主吸收] → [GDT 极高压初级] → [TVS 精密钳位] → 负载 (推荐型号：MOV选 14D431K，430V，能量140J)

4. 电位器 & 数字电位器 (DigiPOT)

从机械旋钮到数字接口的进化：

  • 碳膜旋转：低成本，寿命10万次（适合音量/亮度旋钮）。
  • 线绕精密：精度高，功率大（适合精密仪器校准）。
  • 多圈精密：360°×N圈，高分辨率（适合基准精密校准）。
  • 贴片微调：PCB焊接，一次调整（适合板级参数调整）。

数字电位器 (DigiPOT) —— SPI/I²C 接口程控阻值：

型号 接口 步数 最大阻值 典型应用
MCP4131 (Microchip) SPI 128步 10kΩ/50kΩ/100kΩ 音量控制/增益调节
AD5241 (ADI) I²C 256步 10kΩ/100kΩ 仪器校准/偏置调节
X9C103 (Xicor) 3线 100步 10kΩ 非易失性，掉电保存

⚠️ 注意：

  • A型电位器 (对数) → 音频音量。
  • B型 (线性) → 线性控制。
  • 切勿混用！

5. 综合保护电路设计案例

场景：24V DC工业设备，额定电流3A 需防：开机浪涌 / 过流 / 感性反峰 / 雷击浪涌

四级联合防护方案：

  1. NTC (浪涌抑制)：$R_{25}=5\Omega$, B=3950。冷态限开机涌流，热态压降<0.5V。
  2. PPTC (过流保护)：Ihold=3A, Itrip=6A。短路自恢复。
  3. MOV (过压泄放)：$V_{1mA}=39V$ (选36D391K)。吸收感性反峰。
  4. TVS (精密钳位)：双向30V。响应时间ns级，最终精密钳位。

USB接口保护方案：

  • PPTC (MF-MSMF050-2)：Ihold=500mA，串联在USB +5V。
  • TVS阵列 (USBL C6-2SC6)：接D+/D-数据线，ESD保护。
  • 22Ω串联电阻：D+/D-各串一颗，阻抗匹配+抑制高频EMI。

6. 选型速查 & 常见误区

选型速查表：

需求场景 选什么 注意什么
温度测量 NTC热敏 ($R_{25}$/B值匹配) B值越大灵敏度越高，精度选≤±1%
开机浪涌抑制 NTC (大功率型) 热态阻值必须足够低，减少损耗
USB过流保护 PPTC (Ihold≤额定电流) Itrip约为Ihold的2倍，留足裕量
AC电源防雷 MOV ($V_{ac} \ge 1.1 \times V_{ac_max}$) 能量选型→按标准8/20μs波形计算
精密参数调节 多圈电位器或DigiPOT 机械型看圈数；DigiPOT看步数分辨率

常见误区：

  • ❌ MOV当TVS用 (用于精密钳位) → ✅ MOV响应慢、钳位电压高，精密钳位用TVS。
  • ❌ NTC直接串在大电流回路不算热态阻值 → ✅ 热态阻值需计算，避免压降过大影响输出。
  • ❌ PPTC选Ihold=工作电流 (无裕量) → ✅ $I_{hold} \ge 1.2 \times I_{normal}$，防止误动作。

7. 特殊电阻速记口诀

  • NTC → 温升阻降
    • 测温/浪涌抑制首选
    • $R_{25}$ 配B值查手册
    • 分压电阻取中间温度
  • PPTC → 自恢复保险
    • $I_{hold} \ge 1.2 \times I_{normal}$

    • 能量要留2倍裕量
  • 电位器 A/B 勿混

    • B型：线性，用于控制
    • 精密调节用多圈
  • DigiPOT 数字调节
    • SPI/I²C 程控阻值
    • 步数决定分辨率

  • 保护电路优先级
    • MOV→GDT (AC防雷)

3. MLCC 温度特性代码

选对才能用对地方（稳定性排序：C0G > X7R > X5R > Y5V）

代码 温度范围 容量变化率 稳定性 典型应用
C0G / NPO -55°C ~ +125°C ±30ppm/°C (极稳定) ★★★★★ 振荡器、精密滤波、RF电路
X7R -55°C ~ +125°C ±15% ★★★★ 通用去耦、旁路电容
X5R -55°C ~ +85°C ±15% ★★★ 低温环境去耦，成本较低
Y5V / Z5U -30°C ~ +85°C -82% ~ +22% ★ 仅用于非关键场合，不推荐

⚠️ 直流偏压效应 (DC Bias Effect)： X5R/X7R在施加直流电压后，实际容量会显著下降。
示例：标称 10µF/10V 的 MLCC，在 5V 工作点实际容量可能只有 3µF！选型时务必查询厂商特性曲线。

4. 耐压与降额使用

电容器必须降额——这不是选修，而是必修！

电容类型 降额标准 说明
陶瓷电容 (MLCC) 工作电压 ≤ 额定耐压 × 50% 直流偏压效应导致容量大幅下降，必须降额
铝电解电容 工作电压 ≤ 额定耐压 × 80% 余量保证超压底底和宿命，5V系统选10V或16V
钽电容 工作电压 ≤ 额定耐压 × 50% 钽电容短路失效会燃烧！降额50%是行业标准

实战案例 (5V系统)：

  • MLCC： 需10µF，应选10V或16V耐压的X7R/X5R（不能直接选5V耐压）。
  • 铝电解： 需100µF滤波，应选10V或16V耐压，不得选6.3V。

5. ESR 与 ESL —— 电容的隐藏参数

概念：

  • ESR (等效串联电阻)： 越低越好，影响高频滤波和去耦性能。过高会导致发热 ($P = I^2 \times ESR$)。
  • ESL (等效串联电感)： 决定高频性能上限。

不同类型表现：

类型 ESR 典型值 ESL 高频性能 选型建议
铝电解 0.1Ω ~ 几Ω 较高 差，不适合高频 配合 MLCC 并联使用
钽电容 0.1Ω ~ 0.5Ω 中等 较好 便携设备优选
MLCC (贴片) 1mΩ ~ 10mΩ 极低 优秀，高频首选 高频去耦首选，靠近 IC
薄膜电容 5mΩ ~ 50mΩ 低 好 音频、精密场合

💡 设计技巧： 电源滤波用铝电解，并联一个 100nF MLCC 弥补高频弱点；IC 电源引脚就近放一个 100nF X7R MLCC，尽量靠近引脚 (<3mm)。

6. 电解电容选型要点

  1. 注意极性： 铝电解和钽电容分正负，反接会损坏甚至爆炸/燃烧。PCB上必须标注极性。
  2. 寿命与温度： 铝电解受温度影响极大。温度每升高10°C，寿命减半（阿伦尼斯定律）。高温环境必须选105°C级，不能用标准85°C级的。
  3. 纹波电流： 超过额定纹波电流会加速老化。需计算电源纹波幅度确认在规格范围内。
  4. 低温性能： 铝电解在低温下ESR大幅上升（-40°C环境可能性能“忙化”）。需在-40°C工作时，选低温型或改用钽电容。

8. 常见误区避坑指南

  1. ❌ 容量越大越好 → ✅ 大容量 MLCC 高频特性差，多个小容量并联效果更优。
  2. ❌ 忽视直流偏压效应 → ✅ X5R/X7R 实际容量远低于标称，必须降额选型（查厂商曲线）。
  3. ❌ 钽电容不降额 → ✅ 钽电容短路失效会燃烧！工作电压必须 ≤ 额定耐压 × 50%。
  4. ❌ 电解电容方向随意 → ✅ 反接有爆炸风险！PCB 上务必标注极性，并且扫板确认。
  5. ❌ 高温环境仍用标准铝电解 → ✅ 高温环境选 105°C 级，或改用钽电容、薄膜电容。

旁路电容

电容器的电容值，应根据电路处理信号的频率，按以下标准确定即可。
（1）DC～数十 MHz：0.1μF。
（2）数十 MHz～数百十 MHz：0.01μF。
（3）数百十 MHz～数百 MHz：1000pF。
（4）数百 MHz～数 GHz：100pF。

宽带宽的放大器中，应取上述多个电容器并联。许多陶瓷电容器的电容会因两端所加直流电压而有较大变化，所以有必要确认一下在叠加有直流电时能否确保静电电容值。

一、旁路电容原理与布局要求

  1. 什么是旁路电容？
  • 定义：并联在电源和地之间的电容。
  • 作用：为高频噪声电流提供低阻抗通路，将噪声“旁路”到地，保护敏感电路。
2. 工作原理

当电源线上出现高频纹波或干扰时，旁路电容呈现低阻抗特性，噪声电流优先流经电容到地，而不是进入IC的电源引脚。

3. 核心作用
  • 减小电源线上的纹波电压。
  • 抑制高速开关产生的共模噪声。
  • 提供瞬态电流的本地储能。
  • 提高电源完整性 (PI)。
4. 四大黄金法则（布局要求）
  • 靠近引脚：电容应尽量靠近芯片的电源引脚，走线长度控制在0.5cm以内。
  • 短路径优先：电源线从引脚到电容再到地，走线越短越好，减小寄生电感 (ESL)。
  • 多过孔接地：电容的接地过孔应紧邻焊盘，至少使用两个过孔以降低阻抗。
  • 优先级排序：小容值电容 (0.1μF) 最靠近芯片，大容值电容可稍远。

警示：布局不佳会导致旁路电容失效，高频噪声依然窜入IC。

二、去耦电容选型

1. 高频与低频去耦电容的区别
特性 高频去耦电容 低频去耦电容
典型容值 0.01μF ~ 0.1μF 10μF ~ 100μF
频率响应 100kHz ~ 100MHz DC ~ 100kHz
电容类型 X7R陶瓷电容 铝电解/钽电容
ESR/ESL 低ESR、低ESL ESR较高、ESL大
应用场景 数字IC、高速芯片 电源输入端、大电流
2. 选型原则
  • 容量匹配：根据IC的动态电流和切换频率计算。通常0.1μF用于高频，10~100μF用于低频。
  • 耐压选择：工作电压的1.5~2倍（如3.3V系统选6.3V或10V）。
  • ESL考虑：高频去耦优先选用0402/0603封装（ESL更小）。
  • 温度特性：X7R陶瓷电容温度特性好 (-55°C~+125°C)，Y5V高温下容量剧降需慎用。

三、电源滤波电路设计

1. 常见滤波电路类型
C型滤波
  • 特点：单纯电容滤波，结构简单、成本低，适用于小功率场合。
  • 结构：电源 → 电容 → 地。

|                       |
|     电源输入          | 输出
o--------+--------------o
         |
        === C
         |
---------+--------- GND
LC型滤波
  • 特点：电感+电容组合，效果好、频带宽，是常用方案。
  • 结构：电源 → 电感 → 电容 → 地。
+-----------+---------+
|           |         |
|   电源    L         | 输出
o----UUU----+---------o
            |
           === C
            |
------------+--------- GND
π型滤波
  • 特点：两电容一电感，效果最佳、体积大，用于敏感电路。
  • 结构：电容1 → 电感 → 电容2 → 地。
+------+-----------+------+
|      |           |      |
|     === C1       |      | 输出
o------+           +------o
       |           |
       |     L     |
       +----UUU----+
       |           |
      === C2       |
       |           |
-------+-----------+------ GND
2. 关键设计参数

  • 截止频率

    • C型滤波：$f_c = \frac{1}{2\pi RC}$
    • LC型滤波：$f_c = \frac{1}{2\pi \sqrt{LC}}$

  • ESR影响：ESR越低，滤波效果越好。陶瓷电容ESR < 10mΩ，电解电容ESR ~ 100mΩ。

  • 布局距离：滤波电容靠近噪声源或敏感器件，走线短而粗。

  • 接地方式：采用星形接地，避免地线回路形成环路噪声。

四、容值组合策略

1. 为什么需要多个电容并联？
  • 频段覆盖：单个电容无法覆盖全频段，大电容高频阻抗高，小电容容量有限。
  • ESL优化：小电容ESL小，高频阻抗低；大电容ESL大，适合低频储能。
  • 瞬态响应：小电容响应快，应对高速切换；大电容储能多，应对大电流。
2. 三级容值组合方案 (100nF + 10μF + 100μF)
级别 容值 类型 频率响应 作用 布局位置
第一级 100nF X7R陶瓷 100kHz~100MHz 高频去耦 最靠近芯片
第二级 10μF 钽电容 10kHz~1MHz 中频去耦 芯片电源引脚
第三级 100μF 电解电容 DC~100kHz 低频储能 电源入口处

六、本课小结

  • 知识点回顾

    1. 旁路电容为高频噪声提供低阻抗路径，布局时必须靠近引脚、走线最短。
    2. 高频去耦电容 (0.1μF) 用于高速切换，低频去耦电容 (10~100μF) 用于大电流。
    3. 电源滤波电路有C型、LC型、π型三种，根据需求选择合适的拓扑。
    4. 三级容值组合 (100nF+10μF+100μF) 覆盖全频段，是常用方案。
    5. 实际设计需通过示波器测量电源纹波，验证滤波效果。

电感

一、电感器工作原理与核心参数

1. 基本工作原理

电感两端的电压与电流的变化率成正比，阻碍电流的突变。

V = L × di/dt
  • ：电感两端电压
  • ：电感值
  • ：电流变化率

2. 四大核心参数

参数名称 定义/物理意义 典型范围/要求
电感值 ($L$) 存储磁场能量的能力
品质因数 ($Q$) 储能与耗能之比
自谐振频率 (SRF) 电感与寄生电容产生谐振的频率
直流电阻 (DCR) 线圈本身的直流电阻

其中，品质因数的计算公式为：

Q = ωL / R

二、高频电感选型黄金法则

  1. SRF 要求：自谐振频率必须高于工作频率至少 2 倍（理想情况为 3-5 倍）。
  2. Q 值要求：在目标频率下需大于 30（射频应用需 $>50$）。
  3. 电流余量：额定电流需考虑峰值电流 + 20% 余量。
  4. 封装选择：优先选择 屏蔽电感 以减少 EMI 辐射；高频应用优选 多层片式或薄膜电感。

三、高频电感 PCB 布局设计要点

  1. 地平面完整性：电感下方必须有连续地平面，提供良好回流路径。
  2. 避免铜皮耦合：电感周围 3mm 内 避免走信号线，防止磁场耦合干扰。
  3. 去耦电容靠近：电感的电源端必须紧贴 100nF + 10μF 去耦电容组合。
  4. 热设计考虑：大电流电感需预留散热空间，必要时添加散热孔。

六、电感器应用常见误区

  1. 误区 1：只看电感值，忽视 SRF 和 Q 值。
  2. 误区 2：在射频电路中使用普通功率电感。
  3. 误区 3：PCB 布局时将电感放在信号线旁边。
  4. 误区 4：忽略电感的饱和电流，导致磁芯饱和。

  6. 误区 6：忽略温度对电感性能的影响。
  7. 误区 7：并联电感时未考虑互感影响。

连接器线缆

一、连接器类型与接口标准

1. 消费电子类

  • USB Type-C：支持 USB 3.2/4.0，速率达 10Gbps，支持 100W PD 快充。
  • HDMI 2.1：带宽 48Gbps，支持 8K@60Hz 视频传输。
  • RJ45 以太网：支持 Cat.5e/6/6A 标准，速率 10Gbps，传输距离 100m。

2. 工业/车规类

  • 圆形连接器：符合 MIL-DTL-38999 军标，防护等级 IP67，插拔寿命 500 次以上。
  • D-SUB 连接器：常见 DB-9/15/25 规格，用于 RS232/485 通讯，单针载流 3A。
  • 板对板连接器：常见间距为 0.5mm / 1.0mm / 1.27mm。

二、电气规格匹配原则

选型时需严格遵循以下余量设计原则：

  1. 电流容量：额定电流需大于实际工作电流，并预留 +30% 余量。
  2. 电压等级：耐压值需大于最高工作电压，并预留 +50% 余量。
  3. 频率特性：高频信号传输需考虑阻抗匹配（例如 USB 3.0 差分阻抗需控制在 90Ω）。
  4. 接触电阻：单个触点的接触电阻应 < 20mΩ，以保证低损耗。
  5. 绝缘电阻：在 500V DC 测试条件下，绝缘电阻应 > 100MΩ。

三、机械可靠性设计

为确保产品在恶劣环境下稳定工作，需关注以下指标：

  1. 插拔寿命

    ：

    • 消费电子：约 500 次
    • 工业应用：约 1000 次
    • 车规级应用：约 5000 次

  2. 锁紧方式：采用螺纹、卡扣或推拉自锁结构，以增强防振动能力。

  3. 防误插设计：通过键位、颜色或形状编码区分，防止插错。

  4. 端子保持力：需 > 15N，防止端子在使用过程中退针。

  5. 极化设计：确保只有唯一正确的插接方向。

四、线缆选型规范

  1. 载流能力：依据 AWG 线规和环境温度进行降额计算，需预留 +30% 余量。
  2. 屏蔽要求：高频信号传输线缆需采用双屏蔽结构（铝箔 + 编织网）。
  3. 阻抗控制：高频线缆需严格控制特性阻抗（常见标准为 50Ω / 75Ω / 100Ω）。
  4. 环境适应性：需具备防水、防油、耐紫外线及耐高低温性能。
  5. 防火等级：需满足 VW-1 / FT4 阻燃标准或低烟无卤要求。

二极管

一、PN结基本原理

1. PN结核心概念

  • 耗尽层：P型与N型半导体结合时，在界面形成的无自由载流子区域。
  • 扩散电流：多数载流子从高浓度向低浓度扩散形成的电流。
  • 漂移电流：电场作用下少数载流子漂移形成的电流。
  • 正向偏置：P接正极，N接负极，耗尽层变窄，电流导通。
  • 反向偏置：P接负极，N接正极，耗尽层变宽，电流极小。

三极管

一、三极管工作原理

1. 核心放大公式

Ic = β × Ib
  • Ic：集电极电流
  • Ib：基极电流
  • β (hFE)：电流放大倍数

2. 三种工作状态

  • 截止状态：Ib ≈ 0，Ic ≈ 0，相当于开关断开。
  • 放大状态：0 < Ib < Ib(sat)，Ic = β×Ib，线性放大。
  • 饱和状态：Ib ≥ Ib(sat)，Vce ≈ 0.2V，相当于开关闭合。

MOSFET

1. MOSFET基本结构与工作原理

  • 特性： 电压控制型器件，输入阻抗极高（>10⁸Ω），几乎不消耗驱动电流。
  • 基本结构（N沟道增强型）：
    • 三极：栅极(G)、源极(S)、漏极(D)。
    • 绝缘层：栅极通过SiO₂与沟道绝缘。
    • 导电机制：N沟道为电子导电（电流D→S），P沟道为空穴导电。
  • 三种工作区：
    • 截止区： $V_{gs} < V_{gs(th)}$，沟道未形成，无电流。
    • 线性区（可变电阻区）： $V_{gs} > V_{gs(th)}$ 且 $V_{ds}$ 较小，如同可变电阻。开关应用主要在此区和截止区切换。
    • 饱和区（恒流区/放大区）： $V_{gs} > V_{gs(th)}$ 且 $V_{ds}$ 较大，用于信号放大。
  • 关键公式：
    • 线性区：$I_d = \mu_n C_{ox} (W/L) [(V_{gs}-V_{th})V_{ds} - V_{ds}^2/2]$
    • 饱和区：$I_d = \mu_n C_{ox} (W/L)/2 \times (V_{gs}-V_{th})^2$
    • 导通判据：$V_{gs} \geq V_{gs(th)} + 2V$（通常需10V才能完全导通）。

2. 关键参数详解（选型必看六大参数）

  • Rds(on) 导通电阻： 决定导通损耗 ($P_{cond} = I^2 \times R_{ds(on)}$)。典型值1~50mΩ，具有正温度系数（高温时增大）。
  • Vgs(th) 阈值电压： 开始导通的最低电压。逻辑电平型为12V（适合MCU直驱），普通型为14V。温度升高时Vth降低。
  • Qg 总栅极电荷： 决定开关速度和驱动能力。$I_{drive} = Q_g / t_{switch}$。
  • Vds(max) 耐压： 必须留30%以上余量（如24V系统选60V器件）。
  • Id(max) 最大电流： 标称值通常为25℃下的理论值，实际需按结温降额使用（通常只能用50%左右）。
  • Vgs(max) 栅极限压： 通常±20V，超过会永久击穿氧化层，驱动电路必须钳位保护。

3. MOSFET驱动电路设计

  • 栅极驱动电阻 Rg 的作用： 限制充放电电流峰值，防振荡/EMI。推荐范围547Ω。高频应用(>500kHz)选210Ω。
  • 高侧驱动——Bootstrap自举电路：
    • 问题： 高侧N-MOS源极不接地，需要浮动驱动电源。
    • 原理： 低侧导通时给自举电容充电，高侧导通时电容提供驱动电压。
    • 限制： 占空比不能达到100%（电容无法充电）。
    • 推荐IC： IR2110, IR2104, HIP4082A。
  • 驱动方案选择：
    • 小功率/MCU直驱：<20mA负载。
    • 图腾柱推挽：双BJT，驱动0.5~2A。
    • 专用驱动IC：UCC27517/TC4420等，驱动能力强。
    • 隔离驱动：ACPL-314J/Si8233，用于高压隔离场合。

4. MOSFET热设计

  • 功耗分解计算：

    • 导通损耗：$P_{cond} = I^2 \times R_{ds(on)} \times D$
    • 开关损耗：$P_{sw} = 1/2 \times V_{ds} \times I_d \times (t_r+t_f) \times f_{sw}$
    • 驱动损耗：$P_{gate} = Q_g \times V_{gs} \times f_{sw}$
    • 总功耗：$P_{total} = P_{cond} + P_{sw} + P_{gate}$

  • 热阻模型：

    $T_j = T_a + P_{total} \times (R_{\theta jc} + R_{\theta cs} + R_{\theta sa})$

    • 目标：结温 $T_j$ 需小于 $T_{j_max} - 15^\circ C$（留余量）。

  • 案例： 24V转12V Buck变换器中，需根据总功耗计算所需散热器的热阻。

5. 典型应用电路

  1. 同步整流： 用MOS代替肖特基二极管，效率更高（$V_f < 0.1V$），需互补控制+死区时间。
  2. H桥电机驱动： 4个MOS控制正反转，上桥需自举或隔离驱动，注意死区时间。
  3. 负载开关： 软件控制板级电源通断，可用集成方案（如TPS22918）。
  4. Buck变换器： 高频化可减小L/C体积，但驱动损耗随频率增加。
  5. 电源防反接： 利用P沟道或N沟道+电荷泵实现低压降防反接。
  6. 模拟开关/多路选择： 低频信号切换，选低Rds(on)和低Vgs(th)型号。

6. MOSFET选型速查表

  • 5V/12V开关电源： 选≤30V，超低Rds(on)，如CSD17570Q5B。
  • 24V工业电源： 选耐压≥60V，低Rds(on)，如IPD80N04S4。
  • PFC/LLC高压变换： 选耐压≥650V超结MOS，如IPP60R125CFD7。
  • 电机驱动H桥： 选配对互补MOS，强体二极管，如SI2302/SI2333DS。
  • MCU逻辑直驱： 选逻辑电平MOS（Vgs(th)<2V），如AO3400。
  • 负载开关/防反接： 选P沟道或集成负载开关，如TPS22918。
  • 选型原则： 耐压留1.5~2倍余量；功率管必须核算结温；高频应用重点关注Qg和开关损耗。

7. 常见误区与避坑指南

  • ❌ Vgs越高越好： 错！超过Vgs(max)（通常±20V）会永久击穿。
  • ❌ 可以省略栅极电阻Rg： 错！无Rg会导致振荡和严重EMI。
  • ❌ 体二极管当续流二极管用： 错！体二极管反向恢复慢(t_rr大)，大电流下发热严重，应外加肖特基。
  • ❌ 按Id(max)额定值设计： 错！实际工作需大幅降额。
  • ❌ 高频下开关损耗可以忽略： 错！200kHz以上开关损耗往往是发热主因。
  • ❌ 高侧N沟道不需要浮动驱动： 错！必须用自举或隔离驱动。
  • ❌ 静电防护无所谓： 错！MOS极易被静电击穿，操作必须防静电。

8. 本节小结

  • MOSFET是电压控制器件，核心在于理解三个工作区及关键参数（Rds(on), Qg, Vgs(th)）。
  • 设计中必须考虑驱动电路（特别是高侧驱动）和热设计（结温核算）。
  • 务必遵守安全规范：耐压留余量、防静电、加栅极电阻、注意体二极管特性。

运放

1. 运放简介与理想假设

  • 内部三级结构：
    • 差分输入级： 高输入阻抗，提取差模信号，抑制共模噪声。
    • 中间增益级： 极高开环增益（典型>100dB），提供主要放大能力。
    • 输出级： 低输出阻抗，采用推挽/Class-AB结构，用于驱动负载。
  • 理想运放三大假设（分析基础）：
    • 开环增益 Aol： 理想为无穷大（∞），实际如μA741约为100dB。
    • 输入阻抗 Zin： 理想为无穷大（∞），实际双极型约2MΩ，FET型可达1TΩ。
    • 输出阻抗 Zout： 理想为0，实际约75Ω。
    • 带宽 BW： 理想为无穷大（∞），实际从1MHz到几GHz不等。
    • 失调电压 Vos： 理想为0，实际范围1μV~5mV。

2. 两大黄金法则（负反馈条件下）

这是分析所有线性运放电路的核心工具：

  • 虚短 (Virtual Short)：

    $V_+ \approx V_- = 0V$（两输入端电位趋于相等，非真正短路）。

    • 前提： 必须存在负反馈闭环。

  • 虚断 (Virtual Open)：

    $I_1 = I_2$（流入两输入端的电流为零，非真正断路）。

    • 基础： 输入阻抗趋近于无穷大。

  • 分析三步法：

    1. 确认有无负反馈。
    2. 用“虚短” ($V_+=V_-$) 列节点方程。
    3. 用“虚断” ($I=0$) 简化方程求输出电压 $V_o$。

3. 五种基本运放电路

  • 同相放大器：
    • 公式：$V_{out} = V_i \times (R1+R2)/R2$
    • 特点：高输入阻抗，输出与输入同相。
  • 反相放大器：
    • 公式：$V_{out} = (-R2/R1) \times V_i$
    • 特点：输入阻抗等于Rin，输出与输入反相180°。
  • 差分放大器：
    • 公式：$V_{out} = (V_y - V_x)(R1+R2+R3)/R2$ （注：此处公式可能基于特定电阻匹配条件，通用公式通常涉及电阻比值）
    • 特点：高共模抑制比(CMRR)，需精密电阻匹配。
  • 积分器：
    • 公式：$V_{out} = [(-1)/(R1 \times C1)] \int V_1 dt$
    • 作用：将方波转换为三角波，进行时间积分。
  • 微分器：
    • 公式：$V_{out} = -i \times R2 = -(R2 \times C1) dV_1/dt$
    • 作用：将三角波转换为方波，对高频敏感。

4. 运放关键参数详解

选型时需重点关注以下六大参数：

  • GBW (增益带宽积)： $GBW = \text{增益} \times \text{带宽} = \text{常数}$。决定了在特定增益下的可用带宽。范围通常在1MHz~3.8GHz。
  • SR (压摆率)： 大信号下的最大电压变化率 ($dV_o/dt$)。单位V/μs，范围0.5~5000V/μs。SR不足会导致正弦波变三角波。
  • Vos (失调电压)： 直流误差源。精密测量需选<100μV的型号。
  • Ib (偏置电流)： 输入端流过的微小电流。高阻源应用必须选JFET或CMOS输入型（fA~100nA级别）。
  • CMRR (共模抑制比)： 抑制共模噪声的能力。差分应用中越高越好，典型值60~120dB。
  • R-R (轨到轨输出)： 输出电压能接近电源轨 ($V_{CC}$ ~ GND)。传统运放会有1~2V的压降损失，R-R型更适合单电源低压系统。

5. 典型应用电路

  • 电压跟随器/缓冲器： 增益=1，用于传感器隔离、ADC前端驱动，需选低Ib型防止加载效应。
  • 精密整流器： 利用运放消除二极管0.7V死区，可处理mV级小信号，用于AC测量和峰值检波。
  • 仪表放大器 (INA)： 三运放结构，单电阻调增益，具有极高的CMRR和输入阻抗。推荐型号：INA128, AD8221。
  • 有源低通滤波器： 如Sallen-Key二阶低通，用于ADC抗混叠和音频处理。
  • 比较器注意事项： 运放开环使用即为比较器，但响应慢（μs级），专用比较器更快（ns级）。LM393等集电极开路(OD)输出需加上拉电阻。

  • 音频放大 (Hi-Fi)： NE5532, OPA2134, LM4562
  • 精密直流测量： OPA277, AD8628, LTC2057 (关注低Vos)
  • 高速信号处理： AD8099, OPA847, THS3001 (关注高GBW, 高SR)
  • 高阻传感器接口： TL071, OPA128, AD8610 (关注低Ib)
  • 电池/低功耗： MCP6001, LPV521, MAX4239
  • 仪表放大应用： INA128, AD8221, INA333
  • 比较器应用： LM393, TLV3201, ADCMP601

7. 常见误区警示

  • 虚短虚断并非万能： 仅在负反馈闭合、线性区成立！正反馈（如施密特触发器）或饱和时不适用。
  • GBW不等于带宽： 可用带宽 = GBW ÷ 闭环增益。例如增益100倍时，1MHz的运放带宽仅剩10kHz。
  • 运放不能随意代替比较器： 运放从饱和恢复很慢（μs~ms），且输出结构不同，专用比较器响应更快（ns级）。
  • 单电源运放处理负压： 单电源下输出范围是GND~Vcc，处理双极性信号需加偏置电路（虚地）。
  • 去耦电容不可省： 高速运放极易因电源噪声振荡，每个电源脚必须紧靠引脚放置100nF + 10μF电容。

功率器件

这份资料是《电子元器件基础》系列课程中关于**功率器件（Power Devices）**的详细学习笔记，重点讲解了MOSFET、IGBT和SCR三种核心器件的原理、选型及应用。以下是为您整理的核心要点：

1. 功率器件全景概览

主要对比了四种主流功率器件的特性与应用场景：

  • 功率 MOSFET：
    • 电压/频率： <600V / 高频 (kHz~MHz)。
    • 应用： 开关电源、低压驱动。
  • IGBT：
    • 电压/频率： 600V6.5kV / 中频 (kHz数十kHz)。
    • 应用： 变频器、逆变器、新能源。
  • SCR (晶闸管)：
    • 电压/频率： 200V数kV / 低频 (工频kHz)。
    • 应用： 整流/调压、软启动。
  • SiC MOSFET：
    • 电压/频率： 600V~1700V / 极高频 (MHz)。
    • 应用： 新能源汽车、光伏逆变。

2. IGBT (绝缘栅双极型晶体管)

结构与原理

  • 本质： BJT + MOSFET 的融合体，兼具高压、高速和易驱动特性。
  • 等效结构： 输入端为 N-MOSFET（控制基极电流），输出端为 PNP BJT（实际导通路径）。
  • 工作状态：
    • 截止： Vge < Vge(th)，无集电极电流。
    • 导通： Vge > Vge(th)，MOSFET导通驱动BJT饱和，Vce(sat)低 (1.5~3V)。
    • 关断： 撤除Vge，存在拖尾电流现象。

六大关键参数

  • Vce(sat)： 饱和压降 (1.5~3V)，决定导通损耗。
  • Ic： 最大集电极电流 (10A1000A+)，需留23倍裕量。
  • Vces： 最大耐压 (6006500V)，需留3050%裕量。
  • Vges： 栅极电压范围 (±20V)，过压会击穿氧化层。
  • toff/tf： 关断拖尾时间 (100ns~2μs)，决定最高频率。
  • SOA： 安全工作区，短路保护设计的依据。

驱动电路设计

  • 驱动电压： 导通+15V，关断建议-5V~-15V（负压抑制米勒效应）。
  • 栅极电阻 Rg： 控制开关速度与EMI平衡，典型值5~47Ω。
  • 隔离与保护： 高侧必须隔离（光耦/变压器）；必须具备DESAT去饱和检测防短路；上下桥臂切换需设置死区时间 (2~4μs)。

损耗计算与热设计

  • 导通损耗： $P_{cond} = V_{ce(sat)} \times I_c \times D$
  • 开关损耗： $P_{sw} = (E_{on} + E_{off}) \times f_{sw}$
  • 结温计算： $T_j = T_a + P_{total} \times (R_{jc} + R_{cs} + R_{sa})$
  • 注意： 频率越高开关损耗占比越大，超过20kHz建议考虑SiC MOSFET。

3. SCR (硅控整流器/晶闸管)

工作原理

  • 结构： PNPN四层器件。
  • 状态： 正向阻断 → 触发导通 (Vak>0, Ig>Igt) → 维持导通 (Ia>Ih) → 关断 (Ia<Ih或Vak<0)。
  • 特点： 一旦导通，门极失去控制作用，无法主动关断。

关断方法

  • 自然换相： 利用交流电过零点关断。
  • 强迫换相： 并联电容强制拉低电流（用于DC电路）。
  • 降低负载电流： 调节电路使电流小于维持电流。

关键参数

  • VDRM： 正向断态峰值电压。
  • IT(AV)： 通态平均电流。
  • Igt/Vgt： 触发电流/电压。
  • tq： 关断时间。

传感器

这份资料是《电子元器件基础》系列课程中关于**传感器（Sensors）**的系统性讲解，内容涵盖了从基本概念、核心参数到各类常用传感器（温度、电流、位移等）的原理对比、信号调理及选型避坑指南。以下是为您整理的核心要点：

1. 传感器基本概念与分类

  • 定义： 将非电量（如温度、压力、位移、光强等）转换为可处理电信号（电压、电流、频率）的装置。
  • 四大分类维度：
    • 按被测量： 温度、压力、位移、流量、光电传感器等。
    • 按工作原理： 电阻式、电容式、电感式、压电式、热电式、光电式、磁电式等。
    • 按输出信号：
      • 模拟量： 连续变化的电压或电流。
      • 数字量： 脉冲或总线通信。
      • 开关量： 简单的ON/OFF状态。
    • 按供电方式：
      • 有源： 需要外部供电（如霍尔传感器）。
      • 无源： 自发电（如热电偶、压电传感器）。

2. 核心性能指标（选型六大参数）

在选型时，必须关注以下六个关键指标：

  • 量程 (Range)： 能测量的最大/最小值范围。注意： 超量程可能损坏器件。
  • 精度 (Accuracy)： 测量结果与真实值的偏差，通常以满量程百分比 (%FS) 表示。
  • 分辨率 (Resolution)： 能检测到的最小变化量。模拟传感器受噪声限制，数字传感器由位数决定。
  • 灵敏度 (Sensitivity)： 输出变化量与输入变化量的比值（单位如 mV/℃、mV/Pa）。
  • 响应时间 (Response Time)： 输出从10%变化到90%最终值所需的时间，是动态测量的关键指标。
  • 稳定性 (Stability)： 包括长期漂移（老化）和温漂（温度系数TC），影响长期测量精度。

  • 霍尔位置传感器： 无接触，寿命长，常用于BLDC换相检测。

其他重要传感器

  • 压力传感器： 基于MEMS压阻效应，输出差分mV级信号，需仪表放大。
  • 加速度计： MEMS电容式，用于姿态检测、振动监测（如ADXL345）。
  • 光电传感器： 光敏电阻（慢）、光电二极管（快）、光电三极管（内置放大）。
  • 环境类： 湿度（电容式SHT31）、气体（MQ系列）、超声波测距（HC-SR04）。

4. 信号调理基础

传感器输出的原始信号通常微弱或含有噪声，需要经过调理才能进入ADC：

  • 标准链路： 传感器 $\rightarrow$ 激励源 $\rightarrow$ 差分放大(仪表放大器) $\rightarrow$ 滤波 $\rightarrow$ 电平转换 $\rightarrow$ ADC。
  • 关键组件：
    • 激励源： PT100需恒流源防自热；桥式传感器需恒压源。
    • 仪表放大器 (INA)： 高共模抑制比(CMRR)，适合提取微弱差分信号（如INA128）。
    • 滤波设计： 一阶RC低通最简单有效；二阶Sallen-Key截止更陡；工频干扰需加50/60Hz陷波。

5. 选型速查与应用误区

选型速查表

  • 工业温度监控： 选PT100 + INA128 + ADC（注意4线法消线阻）。
  • 家电/电池保护： 选NTC 10kΩ + 分压电路（注意非线性补偿）。
  • 变频器电流检测： 选ACS712或霍尔CT（注意带宽匹配）。
  • 伺服电机位置： 选增量编码器（注意差分接线抗干扰）。

五大常见误区（避坑指南）

  1. PT100接线错误： 长距离传输用2线法会导致巨大误差（线阻计入测量值），必须用3线或4线法。
  2. 忽略冷端补偿： 热电偶测量的是温差，直接使用必须配合MAX31855等芯片进行冷端补偿。
  3. NTC不做线性化： NTC是非线性的，直接映射温度误差极大，需用Steinhart-Hart方程或查表法。
  4. 编码器信号干扰： 长距离传输TTL电平易受干扰，超过1米必须使用差分RS422接口。
  5. 量程选择过大： 例如5A系统选50A传感器，会导致小电流下信噪比极差，精度损失严重。建议量程为最大值的1.5~2倍。

稳压二极管选型

这份资料是《电子元器件基础》系列课程中关于**稳压二极管（Zener Diode）**的详细学习笔记，内容涵盖了从原理特性、关键参数到典型应用、设计避坑及选型流程的完整知识体系。以下是为您整理的核心要点：

1. 稳压二极管 V-I 特性与结构

  • 核心原理： 利用 PN 结的反向击穿特性来实现稳压。在反向击穿区，电流变化很大时，电压基本保持不变。
  • 电路符号：
    • 阴极（Cathode）：标有黑环的一端，对应电路符号中的短横线侧 (-)。
    • 阳极（Anode）：对应电路符号中的三角形侧 (+)。
  • 工作区域： 正常稳压工作时，处于反向偏置状态（即阴极接高电位，阳极接低电位）。

2. 关键参数详解（选型必看）

选型时需重点关注以下六个核心指标：

参数 符号 典型值/范围 工程说明
稳压电压 $V_z$ 2.4V ~ 200V 工作在反向击穿区时的稳定电压值。
稳压电流 $I_z$ 5mA ~ 50mA 维持稳压所需的最小测试电流（通常指 $I_{zt}$）。
最大功率 $P_z$ 0.3W / 0.5W / 1W / 5W $P_z = V_z \times I_{z_max}$。注意：需降额 70% 使用。
动态阻抗 $Z_z$ 2Ω ~ 100Ω 越小稳压效果越好，曲线越平坦。

3. 三大典型应用场景

简单稳压电路

  • 电路结构： $V_{in} \rightarrow R_{串联} \rightarrow \text{负载} \parallel \text{Zener}$。
  • 稳压条件： $V_{in} > V_z$，且必须串联限流电阻 $R$。
  • 电阻计算： $R = (V_{in_max} - V_z) / I_{z_max}$。
  • 优缺点： 极简、无需 IC；但效率低，负载变化会直接影响稳定性。

限压保护电路

  • 保护对象： 单片机 IO 口或模拟输入端。
  • 连接方式： 并联在信号线与 GND 之间。
  • 双向保护： 使用双向 TVS 管或两只背靠背（阳极相连）的 Zener 管。
  • 注意事项： 需串联限流电阻防止过流烧毁。

与 TL431 对比

  • TL431 特点： 可调精密稳压源，基准电压 $V_{ref} = 2.495V$。
  • 精度对比： TL431 ($\pm 1%$) 优于普通 Zener ($\pm 5%$)。
  • 成本差异： Zener 极便宜（约 ¥0.05），TL431 稍贵（约 ¥0.3）。
  • 选型建议： 低精度/低成本/简单保护选 Zener；精密稳压/可调电压选 TL431。

4. 设计要点与常见误区

  • 必须串联限流电阻： 稳压管不能直接接电源，否则超过最大电流 $I_{z_max}$ 会立即烧毁。
  • 功率降额使用： 实际功耗 $P = V_z \times I_z$。设计时按额定功率的 70% 降额，散热差时需进一步降额。
  • 稳压精度有限： 普通稳压管精度仅 $\pm 5%$ 且随温度漂移。若需高精度，应选用 TL431 或专用基准源。
  • 负载变化影响稳压： 负载电流增加会导致流过稳压管的电流减小，稳压效果变差。若负载变化大，建议改用 LDO。
  • 双向保护接法： 保护双极性信号线时，两只稳压管需背靠背（阳极对阳极）串联后接在信号线与 GND 之间。

  • 温补： $V_z < 5V$ 为负温系数，$V_z > 5V$ 为正温系数（约 5.1V 时温度稳定性最好）。
  • 公式： 限流电阻 $R = (V_{in_max} - V_z) / I_{z_max}$；功率使用需打 7 折。
  • 替代： 精密稳压首选 TL431（$\pm 1%$，可调，带隙基准）。
  • 性能： 动态阻抗 $Z_z$ 越小，稳压效果越好。

MOSFET选型

这份资料是《电子元器件基础》系列课程中关于 MOSFET 选型及开关应用 的详细学习笔记。内容从功率损耗计算入手，深入讲解了散热设计、驱动电路、同步整流选型以及常见的失效模式分析。

以下是为您整理的核心要点：

1. 功率损耗计算

MOSFET 的总损耗由三部分组成：导通损耗 ($P_{cond}$) + 开关损耗 ($P_{sw}$) + 驱动损耗 ($P_{gate}$)。

损耗计算公式与特性

损耗类型 公式 关键参数说明 工程建议
导通损耗 ($P_{cond}$) $D \times I_d^2 \times R_{ds(on)}$ $D$: 占空比 (0~1) $I_d$: 漏极电流 $R_{ds(on)}$: 导通电阻 - 温度升高会导致 $R_{ds(on)}$ 增大（约 +0.5%/℃）。 - 实际选型需降额：$R_{ds(on)actual} = R{ds(on)25^\circ C} \times (1.5 \sim 2.0)$。 - 低频场景 (<50kHz)：优选 $R{ds(on)}$ 小的管子。
开关损耗 ($P_{sw}$) $(E_{on} + E_{off}) \times f_{sw}$ $E_{on/off}$: 开通/关断能量 $f_{sw}$: 开关频率 - 与频率成正比，高频下占比大。 - 米勒平台越短 ($Q_{gd}$小)，开关越快，损耗越小。 - 高频场景 (>200kHz)：优选 $Q_g/Q_{gd}$ 小的管子。
驱动损耗 ($P_{gate}$) $Q_g \times V_{gs} \times f_{sw}$ $Q_g$: 栅极电荷 $V_{gs}$: 驱动电压 通常较小，可忽略。

综合评估指标 (FOM)：在中频段 (50~200kHz)，使用 $FOM = R_{ds(on)} \times Q_g$ 来综合评估器件性能。

2. 热阻模型与散热设计

散热的核心目标是确保结温 $T_j$ 不超过最大允许值（通常需留 20% 余量）。

热阻链模型

热量传递路径：芯片结 ($T_j$) $\rightarrow$ 外壳 ($T_c$) $\rightarrow$ 散热器 ($T_s$) $\rightarrow$ 环境 ($T_a$)

  • 结温计算公式：

    $$T_j = T_a + P_{total} \times (\theta_{JC} + \theta_{CS} + \theta_{SA})$$

    • $\theta_{JC}$: 结到壳热阻（Datasheet提供）
    • $\theta_{CS}$: 壳到散热器热阻（导热垫，约 0.5~2 ℃/W）
    • $\theta_{SA}$: 散热器到环境热阻（需计算或查表）

  • 安全准则： 确保 $T_j < T_{j(max)} \times 0.8$。

常见封装热阻参考

封装类型 $\theta_{JC}$ (结到壳) 适用功率范围 备注
TO-220 1 ~ 3 ℃/W 5 ~ 50W 通孔安装，需加散热器
TO-247 0.5 ~ 1 ℃/W > 50W 大电流场合首选
TO-263 (D2PAK) 1 ~ 2 ℃/W 10 ~ 30W SMD封装，靠PCB散热
SOT-23 / DFN 50 ~ 200 ℃/W < 2W 小信号/低功率，难散热

3. 高低侧驱动电路设计

低侧 NMOS 驱动 (简单)

  • 特点： Source 接 GND，$V_{gs} = V_g$，MCU 可直接驱动 (3.3V/5V)。
  • 关键元件：
    • 栅极电阻 $R_g$ (10~100Ω)： 抑制振荡，控制 $dV/dt$。阻值越大 EMI 越低，但开关变慢。
    • 下拉电阻 (10~100kΩ)： 防止上电瞬间误导通。
    • TVS管： 保护栅极，防止 $V_{gs}$ 超过 20V 击穿。

高侧 NMOS 驱动 (自举电路)

  • 难点： Source 电位浮动，$V_{gs}$ 需要跟随 Source 浮动。

  • 解决方案：

    使用自举电容 ($C_{boot}$) + 自举二极管 ($D_{boot}$) 产生浮动电源。

    • 低管导通时给 $C_{boot}$ 充电，高管导通时放电驱动。

  • 专用驱动 IC： 如 IR2104/IR2110/HIP4082，内置死区时间控制和欠压保护。

  • 死区时间： 必须设置，防止上下管直通短路。

4. 同步整流 MOSFET 选型

用低侧 NMOS 取代传统的续流二极管（肖特基），以降低大电流下的导通损耗。

为什么用同步整流？

  • 传统二极管： 正向压降 $V_f \approx 0.3 \sim 0.6V$。例如 5A 输出时，$P = 5A \times 0.4V = 2W$。
  • 同步整流 MOSFET： 导通压降 $V_{sd} = I_d \times R_{ds(on)}$。若 $R_{ds(on)}=5m\Omega$，则 $P = 25A^2 \times 5m\Omega = 3.1W$（注：此处原文示例数值可能有误，通常大电流下 MOS 优势更明显，如 25A 时二极管损耗高达 10W+，而 MOS 仅 3W）。结论：电流越大，MOSFET 优势越明显。

选型要点

$I_{d(max)}$ $\ge$ 输出电流 $\times 1.5$ 降额使用

体二极管 trr 反向恢复时间要短 $< 50ns$，防止反向恢复损耗过大

  • 失效防护： 过压用 TVS，过流用 OCP，ESD 用钳位。

LED与光耦

这份资料是《电子元器件基础》系列课程中关于 LED（发光二极管）与光耦（光电耦合器） 的详细学习笔记。内容涵盖了从LED的V-I特性、驱动设计，到光耦的工作原理、关键参数（CTR）、隔离应用及选型避坑指南。

以下是为您整理的核心要点：

1. LED V-I 特性与驱动电路设计

  • 核心原理： LED 是电流型器件，不同颜色的 LED 正向压降 ($V_f$) 不同。
  • V-I 特性曲线：
    • 红色 (625nm): $V_f \approx 1.8\text{V}$
    • 绿色 (520nm): $V_f \approx 2.1\text{V}$
    • 蓝色 (470nm): $V_f \approx 3.0\text{V}$
    • 白色: $V_f \approx 3.3\text{V}$
  • 典型工作电流： $20\text{mA}$（切勿超过最大额定值）。

驱动电路设计四步法

  1. 限流电阻计算：
    • 公式：$R = (V_{cc} - V_f) / I_f$
    • 示例： $V_{cc}=3.3\text{V}, V_f=2.1\text{V} (\text{绿}), I_f=10\text{mA} \rightarrow R=(3.3-2.1)/0.01 = 120\Omega$。
  2. 功率计算：
    • 电阻功率：$P_R = I^2 \times R$ 或 $(V_{cc}-V_f)^2/R$
    • LED 功率：$P_{LED} = V_f \times I_f$
    • 注意： 两者均需降额使用（建议留 70% 余量）。
  3. 驱动方式选择：
    • 低亮度 (<20mA): MCU 直驱（需串联 1kΩ 左右电阻）。
    • 中亮度 (20~100mA): 三极管（如 S8050）驱动。
    • 高亮度 (>100mA): 专用 LED 驱动 IC（恒流源）。
  4. PWM 调光：
    • 通过改变 PWM 占空比调节亮度。
    • 频率 $\ge 100\text{Hz}$（避免人眼感觉到闪烁）。
    • 恒流驱动 IC 优先（线性度更好）。

  • 结构： 输入端 LED + 输出端光敏三极管（电气隔离的核心）。

    • 定义：$CTR = I_c / I_f \times 100%$。
    • 趋势：随着使用时间推移，CTR 会下降（老化），设计时需预留裕量。

隔离电压 $BV_{iso}$ 1500V / 2500V / 5000Vrms 安全认证通常需 $\ge 2500\text{V}$。
响应时间 $t_r/t_f$ PC817: ~4μs; 6N137: <0.1μs 高速通信选纳秒级，普通开关选微秒级。
输出饱和压降 $V_{CE(sat)}$ 通常 < 0.4V 影响低电平输出的质量。

4. 光耦驱动设计五要点（避坑指南）

  1. CTR 要留裕量： 选型 CTR $\ge$ 2倍工作所需 CTR；光耦老化后 CTR 下降 30~50%，裕量不足则输出电平偏低或失败。
  2. 输入限流电阻： LED 侧必须串限流电阻：$R_{in} = (V_{in} - V_{f_led}) / I_f$；$I_f$ 通常设 5mA（兼顾寿命与速度）。
  3. 输出上拉电阻： 集电极开路输出需外接上拉电阻到 $VCC_{out}$；$R_{pull}$ 决定输出电压：$V_{out} = VCC_{out} - I_c \times R_{pull}$。
  4. 电源地隔离： 光耦两侧电源地必须完全隔离，PCB 布局时两侧敷铜区不得相连，这是隔离的根本。
  5. 速度与 CTR 权衡： 高 CTR 型响应慢（如 PC817 μs 级）；高速型 6N137 CTR 低但响应 ns 级；二者不可兼得。

5. 典型隔离应用场景

  1. MCU → 高压侧控制： MCU GPIO → 限流 R → 光耦 LED → 光耦输出控制 IGBT/继电器/SSR。
  2. 开关电源反馈隔离： 副边采样电压 → TL431 基准 → PC817 LED → PC817 输出接 PWM 控制器 FB 引脚。
  3. 串口/数字信号隔离： UART TX → 6N137/ISO721 → 对侧 RX（隔离防止两侧地电位不同导致干扰）。
  4. 输入状态检测： 外部高压开关 → 限流 R(10kΩ) → 光耦 → 光耦输出 → MCU GPIO 读取（如 AC220V 检测）。
