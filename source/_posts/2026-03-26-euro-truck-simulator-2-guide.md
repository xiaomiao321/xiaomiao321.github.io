# PXN V9Gen2方向盘使用方法

##  方向盘参数

- **旋转角度**：900°
- **力反馈**：双电机力反馈
- **兼容平台**：PC / PS4 / PS5 / Xbox One / Xbox Series X|S / Switch
- **连接方式**：USB 有线连接
- **踏板**：三踏板（油门、刹车、离合）
- **换挡方式**：支持 H 档和序列档

## 接线

把档、踏板都接入方向盘对应插口，再把方向盘接到电脑。

> [!NOTE]
>
> 方向盘的灯光应该是红色而非紫色，可以通过长按 mode 键调整

## 驱动安装

1. 访问莱仕达官网下载对应驱动
2. 安装完成后连接方向盘自动识别

## 游戏设置

以欧卡 2 为例，进入设置——控制，依次设定方向控制、油门控制、制动控制、离合控制。

设定方法：点击要设定的项目并操作对应外设。

## 常见问题

### 方向盘无法识别

- 检查 USB 连接是否牢固
- 尝试更换 USB 接口
- 重新安装驱动

### 力反馈效果弱

- 在游戏设置中调高力反馈强度
- 检查电源适配器是否连接正常

### 踏板无响应

- 检查踏板线是否插入方向盘对应接口
- 在驱动软件中校准踏板

# 变速箱系统

## 变速箱核心机制

为了获得最优化的功率输出表现：

$$
功率 = 扭矩 \times 转速
$$

$$
Gear Ratio = \frac{n_1}{n_2} = \frac{d_2}{d_1} = \frac{T_2}{T_1}
$$

其中：
- $n$：转速
- $d$：直径
- $T$：扭矩

齿轮比就是在扭矩和转速之间做取舍。

![变速箱原理](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/373d016b962ab0ea58ff007c23dc72a5.jpg)

![齿轮比示意](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/30764aefacad46c39b6dd63137f47339.jpg)

## 变速箱类型

### MT (Manual Transmission) 手动挡变速箱

手动操作离合和挂档来改变不同齿轮之间的组合。

- **家用车**：大部分 6 档
- **半挂车**：12 档、18 档

#### 档位多的好处

1. 改善动力分配
2. 换挡更加平顺
3. 燃油经济性

家用车通常 1 档起步，2 档提速——舍弃扭矩，获得转速。

#### 半挂车档位系统

半挂车有两个拨片——**预选阀**和**高低速拨片**。

![半挂车档位](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/c9e0611e1c6813a51736d12bc4d3273c.jpg)

![档位拨片](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/41fd6e6e6be0beb41a55f6022879497d.jpg)

- **高低速（Splitter）**：把一个档位分为高低两档
- **预选阀（Range Selector）**：把 1-6 改成 7-12

![高低速拨片](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/2298faac3e469d59ff789a94468eee5f.jpg)

部分车辆有两个挡把，相当于 1 个主档有四个分档，共 6×4=24 个档位。

![双挡把](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/b127cfa6a3d977bb7e772f20070c8be8.jpg)

### AT (Automatic Transmission) 自动挡变速箱

自动换挡，无需手动操作离合。

### AMT (Automatic Manual Transmission) 手自一体变速箱

与手动变速箱基本一致，只是由电脑选择档位和离合时机。

- **优点**：方便、经济性
- **缺点**：如长下坡不一定合适

# 离合系统

## 离合的目的

如果车轮是停止的，要是没有离合，引擎也会被迫停止。

![离合原理 1](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/fd1b69b81f9f62484192c24335662e15.jpg)

![离合原理 2](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/1bcba2486f4a7516b63bb5114384aa42.jpg)

在车辆停之前，通过踩离合使得引擎与变速箱完全脱离，这样车子停住后，引擎仍可以保持最低转速运行。

![离合原理 3](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/img/8c8b3a230d36d74b41d68e359801442d.jpg)

因此，减速停车需要刹车离合一起踩。

作用就是在必要情况下把输出动力的引擎与变速箱隔开，如换挡时要断开和发动机的链接来改变变速箱的齿轮组合。

## 离合的工作原理

![](https://photos-1355819942.cos.ap-shanghai.myqcloud.com/59-2202111955202P.webp)

- **不踩离合**：红色部分被连接在引擎上，飞轮巨大的摩擦力带动，从而带动其上主动轴一起转动
- **踩离合**：黄色、红色与主动轴脱离

# 换挡技巧

## 基本操作

1. 先踩离合，再换挡
2. 挂档注意横平竖直

## 升档方法

踩离合，挂高挡位，慢慢松离合，半联动时候稳住离合，轻点油门。

> [!IMPORTANT]
>
> 离合在**半触点稳住 1-2 秒再松**，不可越级加挡

### 两脚离合

1. 第一次：松油门的时候踩离合，挂空挡
2. 第二次：挂新档

**升档**：1000-1500 转之间（1500 转左右最常见）

### 不踩离合换挡

1400 转挂空挡，掉到 1100 再升档。

## 降档方法

先踩刹车减速再降档，可以跨级降档。

**降档转速**：1000-1100 转

操作步骤：
1. 加点油门
2. 等到感觉发动机声音响亮
3. 左脚踩离合，右脚松油门
4. 离合在半触点稳住 1-2 秒再松

# 控制台指令

## 激活开发者模式

进入"库→我的文档→Euro Truck Simulator 2"，在 Euro Truck Simulator 2 目录下找到 `config.cfg` 文件，用记事本打开，找到：

```
uset g_console 0
uset g_developer 0
```

将两者后面的 `0` 改成 `1`，点击保存即可！建议备份 `config.cfg` 原文件。

## 常用指令

进入游戏后，按 `~` 键调出控制台，输入以下指令：

```bash
g_minicon 1                    # 顶端显示信息
g_fps 1                        # 显示FPS（需：g_minicon 1）
g_flyspeed #                   # 设置自由视角速度（#默认是100），如调到1000则是10倍速度
goto -44831.8;112.729;-40232.4 # 传送到地图上对应坐标区域
goto 城市名                     # 传送到游戏中城市（如：goto berlin）
warp #                         # 设置游戏与真实速度比（如 warp 0.8 则是现实世界80%速度）
g_set_time 小时 分钟            # 设置游戏时间（24小时制为具体时间：如 g_set_time 14，则为下午2时）
g_set_weather # f/i            # 设置游戏天气（#为天气索引：0-1，或奇偶数切换，实验输入 2 天大晴）
                               # （0：晴天切换，1：雨天切换，f：立刻改变天气，i：逐步改变天气）
g_police #                     # 0、1；设置为0，没有警察，没有处罚
g_traffic #                    # 设置AI交通，0：路上没有AI交通流量
r_fullscreen                   # 开启/关闭 全屏
r_vsync                        # 开启/关闭 垂直同步
s_interior_volume #            # 驾驶舱引擎音量：1.0 – 6.0 [1.0-6.0]
g_set_climate albedo           # 天亮代码
```

## 其他快捷操作

```
飞行模式：大键盘按 0，小键盘845693完成飞行，9上3下
飞到目的地后，按 ctrl+F9 把车也传送到身边
```

输完指令后按 `Enter` 即可生效。
