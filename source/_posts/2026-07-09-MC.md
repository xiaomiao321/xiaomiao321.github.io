## 快捷键

### 物品操作

#### 物品转移

- **拿起/放下整组：** 鼠标左键单击
- **取出一半/放下一个：** 鼠标右键单击
- **平均分配：** 左键按住拖动
- **逐一放置：** 右键按住拖动
- **快速堆叠：** 鼠标左键双击
- **快速转移：** `Shift` + 鼠标单击
- **大量转移：** （悬挂物品时）`Shift` + 左键双击
- **交换物品位置：** （指针对准某格）`1~9` 数字键 或 `F`键
- **快速装备：** （手持装备时）右键单击
- **主副手交换：** `F`键
- **选择交易项：** `Tab`键 或 `"↑"` 和 `"↓"`
- **交易快速补货：** `空格键` 或 `回车键`
- **批量交易：** （对准成品）`Shift` + 鼠标单击
- **放入收纳袋：** （悬挂物品对准收纳袋）左键单击 或 （悬挂收纳袋对准物品）左键单击
- **从收纳袋取出：** （对准收纳袋）右键单击 或 （悬挂收纳袋对准空格）右键单击
- **收纳袋内选择物品：** （对准收纳袋）鼠标中键滚动

#### 物品丢弃

- 快捷栏
    - **单个丢弃：** `Q`键（可按住+滚轮滚动）
    - **整组丢弃：** `Ctrl` + `Q`（可按住+滚轮滚动）
    - **手持收纳袋右键单击丢出其中的物品**
- 物品栏/交互面板
    - **单个丢弃：** `Q`键（可按住+指针移动）
    - **整组丢弃：** `Ctrl` + `Q`（可按住+指针移动）
    - **丢弃单个悬挂物品：** （物品栏范围外）右键单击
    - **丢弃全部悬挂物品：** （物品栏范围外）左键单击

#### 物品合成

- **打开/关闭配方书：** `Tab`键选中 再按 `空格键` 或 `回车键`
- **配方书内搜索：** `T`键
- **快速摆放材料：** （选好待合成物品后）`空格键` 或 `回车键`（可按住）
- **批量摆放材料：** （对准待合成物品）`Shift` + 左键单击
- **批量合成：** （对准成品）`Shift` + 鼠标单击

#### 创造模式

- **拿取整组物品/快速清除物品：** `Shift` + 鼠标单击
- **快速拿取整组物品至对应槽位：** （指针对准物品）`1~9` 数字键 或 `F`键
- **清空物品栏：** `Shift` + 鼠标单击 `"X"`
- **复制物品：** （对准物品）鼠标中键单击
- **大量复制：** （悬挂物品时）中键按住拖动
- **获取物品：** （对准方块/实体）中键单击
- **复制容器/告示牌：** `Ctrl` + 中键单击
- **保存和加载预设：** `C` + 数字键 / `X` + 数字键
- **转至搜索：** （打开物品栏）`T`键

## 附魔

### 一、 附魔基础机制

1.  **魔咒属性**
    *   **等级：** 决定效果强度（通常为I至V级）。I级魔咒若为该魔咒最高等级，则不显示等级数字。
    *   **适用性：** 每种魔咒都有特定的适用物品（如“水下呼吸”仅适用于头盔）。
    *   **兼容性：** 部分魔咒互斥，不能同时存在于同一物品上（如“精准采集”与“时运”）。

2.  **物品显示**
    *   附魔物品具有特殊的光泽效果。
    *   诅咒类魔咒在提示框中以红色文本显示。

---

### 二、 获取附魔的途径

1.  **附魔台（基础途径）**
    *   消耗：经验等级 + 青金石。
    *   限制：无法获得“宝藏魔咒”；部分高等级魔咒（如锋利V、荆棘III）无法直接通过30级附魔获得。
    *   书架：在附魔台周围放置书架可提升附魔等级，最高需要15个书架。

2.  **铁砧（进阶合并）**
    *   功能：通过消耗经验，将两件同类物品合并（取最高等级或升级），或将“附魔书”的效果应用到物品上。
    *   累积惩罚：物品在铁砧上操作次数越多，费用越高。当费用达到40级时会提示“过于昂贵”，生存模式下将无法继续操作。

3.  **附魔书**
    *   用于存储魔咒的载体，可通过钓鱼、宝箱战利品或与图书管理员交易获得。
    *   优势：可针对性地为工具积累魔咒，避免附魔台的随机性。

4.  **自然生成与奖励**
    *   **生物掉落：** 僵尸、骷髅等生物掉落的装备可能自带魔咒。
    *   **战利品箱：** 远古城市、试炼密室、末地城等遗迹中产出的装备附魔等级通常较高。
    *   **交易/以物易物：** 猪灵以物易物产出“灵魂疾行”；村民交易产出大部分魔咒。

---

### 三、 魔咒分类详述

#### 1. 宝藏型魔咒（无法通过附魔台获得）
*   **经验修补（Mending）：** 获得经验球时自动修复物品耐久度。
*   **冰霜行者（Frost Walker）：** 在水面行走产生霜冰。
*   **灵魂疾行（Soul Speed）：** 增加在灵魂沙/土上的移动速度。
*   **迅捷潜行（Swift Sneak）：** 提高潜行速度。
*   **风爆（Wind Burst）：** 重锤下落击中后将玩家弹起。
*   **诅咒系列：** 绑定诅咒（装备后无法卸下）、消失诅咒（死亡后物品消失）。

#### 2. 重锤专用魔咒（2024-2026新增重点）
*   **致密（Density）：** 根据下落距离增加攻击伤害。
*   **破甲（Breach）：** 降低目标的护甲防御效果。

#### 3. 矛/剑/近战魔咒
*   **突进（Lunge）：** 2026年更新内容，进行戳刺攻击时可向前方移动。
*   **锋利/亡灵杀手/节肢杀手：** 增加伤害（三者互斥）。
*   **横扫之刃（Java版专用）：** 增加横扫攻击的伤害。
*   **火焰附加：** 使目标着火。

#### 4. 远程武器魔咒
*   **弓：** 力量、火矢、冲击、无限（无限与经验修补互斥）。
*   **弩：** 多重射击、穿透、快速装填。
*   **三叉戟：** 忠诚（投掷返回）、引雷、激流（激流与忠诚/引雷互斥）。

#### 5. 盔甲与工具魔咒
*   **保护系列：** 保护、火焰保护、爆炸保护、弹射物保护（四者互斥，但“保护”最为普适）。
*   **效率：** 增加挖掘速度。
*   **时运/精准采集：** 增加掉落物数量/原样获取方块（两者互斥）。

---

### 四、 移除魔咒

1.  **砂轮（Grindstone）**
    *   放入附魔物品可移除所有非诅咒类魔咒。
    *   移除后会返还一部分经验值。
    *   注意：诅咒类魔咒（绑定、消失）无法通过砂轮移除。

2.  **合成合并**
    *   在工作台中合并两件磨损的附魔物品会得到一件满耐久但无魔咒的物品（诅咒除外）。

---

### 五、 核心冲突规则（防错指南）

*   **防御类：** 保护、火保、弹保、爆保 只能选其一。
*   **耐久修复类：** 经验修补与无限（弓）不能共存。
*   **采集类：** 时运与精准采集不能共存。
*   **三叉戟类：** 激流不能与忠诚、引雷共存。
*   **近战伤害类：** 锋利、亡灵杀手、节肢杀手只能选其一。

### S级：唯五真神

核心评价：前四项无需多言，属于游戏基石。无限虽与经验修补互斥，但本身强度极高（省背包、连射），配合力量/耐久/火矢可批量获取资源。经修是把箭当消耗品，无限是把弓当消耗品，两者皆强，但经修综合泛用性略高排第一。

1. 经验修补
    - 适用装备：所有可穿戴装备、工具、武器（除胡萝卜钓竿、剪刀、刷怪蛋、鞘翅等）
    - 对应功能：通过收集经验球来修复物品的耐久度，是维持顶级装备永久使用的核心附魔。
2. 耐久
    - 适用装备：所有可穿戴装备、工具、武器、盾牌、打火石、钓鱼竿、胡萝卜钓竿、剪刀、刷怪蛋、鞘翅
    - 对应功能：有概率不消耗耐久度，大幅延长物品使用寿命。
3. 效率
    - 适用装备：镐、锹、斧、锄、剪刀
    - 对应功能：大幅提升挖掘方块和攻击（针对斧）的速度。
4. 保护
    - 适用装备：头盔、胸甲、护腿、靴子
    - 对应功能：减少来自绝大多数伤害来源（如摔落、火焰、爆炸、怪物攻击）的伤害。
5. 无限
    - 适用装备：弓
    - 对应功能：射击时不消耗普通箭矢（只需背包内至少有一支），解决了弓箭手长途作战的弹药焦虑，且支持连射。

### A级：必用神技

核心评价：使用率断层式领先于后续档位，属于功能性或战斗力的质变。

1. 抢夺
    - 适用装备：剑
    - 对应功能：增加怪物死亡时的掉落物数量或稀有掉落物的几率（如珍珠、烈焰棒）。
2. 锋利 (基岩版)
    - 适用装备：剑、斧
    - 对应功能：增加近战攻击伤害。在基岩版中，锋利对亡灵生物同样有效，因此优于亡灵杀手。
3. 力量
    - 适用装备：弓
    - 对应功能：大幅增加弓箭射击造成的远程伤害。
4. 摔落保护
    - 适用装备：靴子
    - 对应功能：大幅减少从高处跌落受到的伤害，并降低跌落后的短暂眩晕时间。
5. 亡灵杀手
    - 适用装备：剑、斧
    - 对应功能：对僵尸、骷髅、凋灵等亡灵生物造成额外巨额伤害。
6. 时运
    - 适用装备：镐、锹、锄
    - 对应功能：增加方块掉落物的数量（如钻石、煤炭、小麦种子），但不适用于精准采集适用的方块。

### B级：不错（特定场景强力）

核心评价：被低估或机制优秀的附魔，在特定环境下不可或缺。

1. 水下速掘
    - 适用装备：头盔
    - 对应功能：消除在水下挖掘方块时的速度惩罚，使水下挖掘速度与陆地一致。
2. 水下呼吸
    - 适用装备：头盔
    - 对应功能：延长水下呼吸时间，并减少水下视野模糊。
3. 深海探索者
    - 适用装备：靴子
    - 对应功能：在水中移动时不受减速效果影响，提升水下机动性。
4. 火矢
    - 适用装备：弓
    - 对应功能：射出的箭矢会点燃目标。对于攻速慢的弓来说，这是弥补单次伤害不足、利用燃烧持续输出伤害的关键手段。
5. 精准采集
    - 适用装备：镐、锹、斧、锄、剪刀
    - 对应功能：使方块以原本的形式掉落（如玻璃、冰块、矿石本身），是建筑和特殊资源获取的必备附魔。
6. 灵魂疾行
    - 适用装备：靴子
    - 对应功能：在灵魂沙或灵魂土上行走时大幅提升速度且不消耗额外饥饿值。相比冰船更灵活，且耐久损耗极低（皮革鞋跑1600格才坏，下界合金鞋可达12000格），是被严重低估的下界交通神技。
7. 穿刺 (基岩版)
    - 适用装备：三叉戟
    - 对应功能：在基岩版中对所有生物（不仅仅是水生生物）造成额外伤害，使其成为通用的强力武器。
8. 快速装填
    - 适用装备：弩
    - 对应功能：减少弩的装填时间。III级可减少60%冷却，攻速提升至2.5倍，相当于弓的力量V带来的提升幅度，极大改善了弩的手感。
9. 火焰保护
    - 适用装备：头盔、胸甲、护腿、靴子
    - 对应功能：专门减少火焰伤害（岩浆、烈焰人、着火），并缩短着火时间。
10. 海之眷顾
    - 适用装备：钓鱼竿
    - 对应功能：增加钓到宝藏（如附魔书、命名牌、鞍）的几率，减少钓到垃圾的几率。
11. 穿透
    - 适用装备：弩
    - 对应功能：箭矢可以穿透多个实体，且穿透后的箭矢可以被回收。这补偿了弩无法使用无限的弊端，适合应对群怪。

### C级：有用但不多

核心评价：有一定作用，但在大多数情况下不如上位替代，或应用场景极其有限。

1. 火焰附加
    - 适用装备：剑
    - 对应功能：攻击时点燃目标。由于剑的攻速快，往往目标在被烧死前就已经被砍死，不如火矢对弓的收益大。
2. 迅捷潜行
    - 适用装备：靴子
    - 对应功能：增加潜行时的移动速度。仅在需要精细操作且不能发出声音的极少数建筑或PVP场景有用。
3. 锋利 (Java版)
    - 适用装备：剑、斧
    - 对应功能：在Java版中，锋利对亡灵生物无效，导致其在面对大量亡灵怪时不如亡灵杀手，通用性受限。
4. 激流
    - 适用装备：三叉戟
    - 对应功能：只能在雨天或水中使用，将玩家像鱼雷一样发射出去。虽然机动性强，但限制了战斗用途，只能作为交通工具。
5. 饵钓
    - 适用装备：钓鱼竿
    - 对应功能：减少等待鱼儿上钩的时间。虽然能加快钓鱼频率，但不如海之眷顾直接提升收益质量重要。
6. 冲击
    - 适用装备：弓
    - 对应功能：增加击退距离。在PVP中可能有用，但在PVE中容易把怪物推远，反而降低输出效率。
7. 引雷
    - 适用装备：三叉戟
    - 对应功能：在雷暴天气下击中生物可召唤闪电。主要用于充能苦力怕或村民转职，实战意义极小。
8. 爆炸保护
    - 适用装备：头盔、胸甲、护腿、靴子
    - 对应功能：减少爆炸伤害。除非长期在下界或末地面对苦力怕，否则通用保护足以应付。
9. 弹射物保护
    - 适用装备：头盔、胸甲、护腿、靴子
    - 对应功能：减少箭矢、雪球等弹射物伤害。针对性太强，泛用性低。
10. 多重射击
    - 适用装备：弩
    - 对应功能：一次射出三支箭但只消耗一支。虽然看起来火力猛，但实际上只有中间那支箭能造成伤害，且分散了单发伤害，不如穿透实用。

### D级：完全没有用

核心评价：机制落后、限制过大或有完美的上位替代。

1. 穿刺 (Java版)
    - 适用装备：三叉戟
    - 对应功能：仅对水生生物有效。在Java版中限制太大，不如直接用锋利或亡灵杀手。
2. 冰霜行者
    - 适用装备：靴子
    - 对应功能：在水面上行走时生成浮冰。不仅破坏水源，而且鞋子耐久掉得飞快，实用性远不如直接搭桥或深海探索者。
3. 击退
    - 适用装备：剑
    - 对应功能：增加击退距离。通常被认为是负面附魔，因为把怪打远了反而难打，除非是为了风筝特定的怪。
4. 节肢杀手
    - 适用装备：剑、斧
    - 对应功能：仅对蜘蛛、蠹虫等节肢生物有效。适用范围比亡灵杀手还窄，完全被锋利替代。
5. 荆棘
    - 适用装备：头盔、胸甲、护腿、靴子
    - 对应功能：受到攻击时有概率反弹伤害给攻击者。但这会大幅加速装备耐久损耗，且反弹伤害微乎其微，得不偿失。

### F级：诅咒

核心评价：纯粹的负面效果，除非为了完成成就或特殊玩法，否则应避免。

1. 消失诅咒
    - 适用装备：所有可穿戴装备、工具、武器
    - 对应功能：玩家死亡后，该物品直接消失，不会掉落。
2. 绑定诅咒
    - 适用装备：所有可穿戴装备（头盔、胸甲、护腿、靴子、南瓜头、头颅）
    - 对应功能：一旦装备上就无法取下，直到物品损坏或玩家死亡。

### 钓鱼专用附魔

1. 海之眷顾
    - 适用装备：钓鱼竿
    - 对应功能：核心附魔。大幅增加钓到宝藏（附魔书、弓、名字牌等）的概率，减少钓到破靴子等垃圾的概率。建议堆满3级。
2. 饵钓
    - 适用装备：钓鱼竿
    - 对应功能：辅助附魔。缩短浮漂等待咬钩的时间，提高单位时间内的钓鱼次数。建议堆满3级。
3. 经验修补
    - 适用装备：钓鱼竿
    - 对应功能：钓鱼是获取经验修补书籍的最佳途径之一，同时钓鱼本身也能获得经验来修复钓竿，实现永动。
4. 耐久
    - 适用装备：钓鱼竿
    - 对应功能：钓鱼竿非常容易损坏（特别是钓到实体时），高耐久是基础保障。

### 补充冷知识

- **牛奶**：饮用后清除所有状态效果（包括正面的），是唯一的万能解药。
- **蛋糕**：放置后右键食用，共6次，每次恢复2饥饿值和0.4饱和度，不可堆叠但可多人共享。
- **腐肉的正确用法**：虽然80%概率获得饥饿效果，但饥饿效果不会致死（最低降到半颗心），且腐肉极易大量获取，在食物短缺时是可靠的应急口粮。
- **饱和度才是核心指标**：金胡萝卜虽然只回6饥饿值（不如熟牛排的8），但14.4的饱和度意味着吃完后很久都不会饿，是长途探索的最佳选择。
- **不可堆叠的食物**（蘑菇煲、甜菜汤、谜之炖菜、兔肉煲、蛋糕）会占用大量背包空间，外出探险时不太方便。





## 酿造

### 1. 基础设备与容器合成

在开始酿造前，你必须先制作出酿造台和玻璃瓶。

| 物品       | 图标参考            | 合成配方 (工作台)                    | 用途说明                                   |
| ---------- | ------------------- | ------------------------------------ | ------------------------------------------ |
| **酿造台** | 类似石头台阶+药水槽 | **烈焰棒** (上方) **圆石** (下方3个) | 核心设备。烈焰棒需击杀烈焰人获得。         |
| **玻璃瓶** | 透明玻璃容器        | **玻璃** (3个，放在工作台顶部一排)   | 药水的容器。玻璃由沙子烧制而成。           |
| **水瓶**   | 装满水的瓶子        | **玻璃瓶** + **水源** (或炼药锅)     | 无任何效果。右键点击水源或炼药锅装水获得。 |



### 2. 核心基础材料获取

这些材料是酿造所有药水的基石，无法通过合成台合成，主要通过**酿造**或**击杀/种植**获得。

| 材料名称     | 获取方式           | 关键用途                                             |
| ------------ | ------------------ | ---------------------------------------------------- |
| **下界疣**   | 下界要塞种植       | 制作**粗制的药水**，所有药水的起点。                 |
| **地狱疣**   | 下界要塞种植       | *注：下界疣的别称，用于制作粗制药水。*               |
| **发酵蛛眼** | 蜘蛛眼 + 糖 + 菌类 | 用于**腐化**药水（使效果变负面或特殊）。             |
| **烈焰粉**   | 杀死烈焰人掉落     | 酿造台的**燃料**，也可直接作为酿造材料（力量药水）。 |
| **岩浆膏**   | 杀死岩浆怪掉落     | 制作**抗火药水**。                                   |
| **恶魂之泪** | 杀死恶魂掉落       | 制作**再生药水**。                                   |
| **幻翼膜**   | 杀死幻翼掉落       | 制作**缓降药水**。                                   |
| **海龟壳**   | 杀死海龟掉落       | 制作**神龟药水**（抗性提升+缓慢）。                  |

### 3. 完整药水酿造配方表

**核心逻辑**：`水瓶` + `下界疣` = **粗制的药水** -> + `影响材料` = **基础药水** -> + `改性剂` = **最终药水**

| 目标药水     | 所需材料 (按顺序)             | 酿造步骤详解                                                 |
| ------------ | ----------------------------- | ------------------------------------------------------------ |
| **治疗药水** | 粗制的药水 + **闪烁的西瓜片** | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 闪烁的西瓜片 = 治疗药水   |
| **抗火药水** | 粗制的药水 + **岩浆膏**       | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 岩浆膏 = 抗火药水         |
| **再生药水** | 粗制的药水 + **恶魂之泪**     | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 恶魂之泪 = 再生药水       |
| **力量药水** | 粗制的药水 + **烈焰粉**       | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 烈焰粉 = 力量药水         |
| **迅捷药水** | 粗制的药水 + **糖**           | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 糖 = 迅捷药水             |
| **水肺药水** | 粗制的药水 + **河豚**         | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 河豚 = 水肺药水           |
| **夜视药水** | 粗制的药水 + **金胡萝卜**     | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 金胡萝卜 = 夜视药水       |
| **隐身药水** | 夜视药水 + **发酵蛛眼**       | 1. 先做出夜视药水 2. + 发酵蛛眼 = 隐身药水 (腐化)            |
| **剧毒药水** | 粗制的药水 + **蜘蛛眼**       | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 蜘蛛眼 = 剧毒药水         |
| **虚弱药水** | 水瓶 + **发酵蛛眼**           | **特例**：直接用水瓶 + 发酵蛛眼酿造。                        |
| **伤害药水** | 治疗药水 + **发酵蛛眼**       | 1. 先做出治疗药水 2. + 发酵蛛眼 = 伤害药水 (腐化)            |
| **迟缓药水** | 迅捷药水 + **发酵蛛眼**       | 1. 先做出迅捷药水 2. + 发酵蛛眼 = 迟缓药水 (腐化)            |
| **神龟药水** | 粗制的药水 + **海龟壳**       | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 海龟壳 = 神龟药水 (缓慢+抗性提升) |
| **缓降药水** | 粗制的药水 + **幻翼膜**       | 1. 水瓶 + 下界疣 = 粗制的药水 2. + 幻翼膜 = 缓降药水         |

### 4. 药水改性与进阶

| 操作             | 添加材料   | 效果                                                         |
| ---------------- | ---------- | ------------------------------------------------------------ |
| **延长持续时间** | **红石粉** | 增加药水的持续时间 (例如从 3:00 变为 8:00)。                 |
| **增强效果等级** | **荧石粉** | 提升药水的等级 (例如力量 I 变为 力量 II)。 *注意：不能对已经延长的药水使用。* |
| **制作喷溅药水** | **火药**   | 使药水可以投掷，造成范围伤害/效果。                          |
| **制作滞留药水** | **龙息**   | 必须在**喷溅药水**的基础上添加，投掷后产生区域效果云。       |

## 交易

以下是根据2026年7月更新的Minecraft Wiki资料整理的村民交易系统知识：

### 一、 核心机制

1. **基本定义**
交易是玩家使用绿宝石与其他物品，向成年职业村民或流浪商人兑换物资的机制。

2. **价格波动因素**
* **声望值（仅Java版）：** 玩家在村庄的行为影响声望。声望越高（如治愈僵尸村民），价格越低；声望为负（如攻击村民），价格会升高。
* **供需关系：** 某项交易若达到次数上限被锁定，补货后价格可能上涨。若玩家长期不进行该交易，价格会逐渐回落。
* **村庄英雄：** 赢得袭击后获得的BUFF，可大幅度降低交易价格。

3. **职业等级**
村民共有5个等级，通过交易获取经验来升级：
* 等级1：新手（石质徽章）
* 等级2：学徒（铁质徽章）
* 等级3：老手（金质徽章）
* 等级4：专家（绿宝石徽章）
* 等级5：大师（钻石徽章）

4. **补货机制**
  每项交易有次数限制，达到上限后会锁定（显示红色叉号）。村民每天会在其认领的工作站点方块处工作，最多补货2次。
5. 刷新物品

只适用于没有交易过得村民，破坏掉工作方块就会失业，之后重新加入职业即可刷新

---

### 二、 村民分类与职业对照

1. **不可交易的村民**
* **幼年村民：** 无法获得职业。
* **傻子：** 穿着绿色袍子，无法获得职业或进行交易。
* **失业村民：** 穿着群系服装但无职业装，可通过摆放工作站点方块转职。

2. **职业与工作站点方块对照表**
* 盔甲匠：高炉
* 屠夫：烟熏炉
* 制图师：制图台
* 牧师：酿造台
* 农民：堆肥桶
* 渔夫：木桶
* 制箭师：制箭台
* 皮匠：炼药锅
* 图书管理员：讲台
* 石匠：切石机
* 牧羊人：织布机
* 工具匠：锻造台
* 武器匠：砂轮

---

### 三、 村民交易平衡性调整（实验性/2026更新特性）

开启“村民交易平衡性调整”后，部分关键职业的规则发生重大变化：

1. **图书管理员（核心变化）**
* 附魔书种类与村民生成的**生物群系**挂钩。
* 每个群系的图书管理员都有“特殊附魔书”（在大师级固定产出）和“普通附魔书”。
* 示例：沼泽群系的图书管理员大师级必出“经验修补”；雪原群系产出“精准采集”；沙漠群系产出“效率III”。
* 移除了部分弩、三叉戟、钓鱼竿的特殊魔咒交易。

2. **盔甲匠**
* 不同群系的盔甲匠出售不同部件和材质的盔甲。
* 购买钻石盔甲现在除了绿宝石外，通常还需要额外支付少量的钻石。
* 针叶林盔甲匠在专家级可能允许用旧钻石装备兑换新钻石装备。

---

### 四、 流浪商人

流浪商人不属于村庄系统，会随机生成在玩家附近。

1. **交易特点**
* 共有9个随机交易项（2个收购项，7个售货项）。
* 不提供职业升级，也不受村庄声望影响。
* 2026年更新后，流浪商人增加了更多收购项（如用水瓶、水桶、干草捆换取绿宝石）。

2. **特殊商品（2026年新增）**
* 包含金蒲公英、杨树树苗、层孔菇、硫黄尖锥等稀有植物或资源。
* 也会出售附魔铁镐、隐身药水、各种花卉和染料。

---

### 五、 其他重要规则

1. **交易展示：** 当玩家手持村民需要的物品时，村民会在手上展示其愿意交换的物品。
2. **解锁逻辑：** 每次升级通常解锁2项新交易。在Java版中，解锁顺序受随机序列和世界种子影响。
3. **经验收益：** 玩家每次成功交易会获得3至11点经验值。
4. **地理限制：** 在实验性玩法中，制图师如果在非主世界维度，将不再出售探险家地图。

### 六、 村民繁殖机制

村民的繁殖不取决于玩家的操作，而是取决于村民自身的意愿和外部环境：

1.  **必要条件：床位数量**
    *   村庄中必须有足够多余的床。只有当床的总数超过现有村民总数（包括幼年村民）时，村民才会进入繁殖状态。
    *   床上方必须至少有2格的透明空间（空气），否则村民无法识别该床为有效床位。

2.  **核心需求：意愿值（食物）**
    *   村民需要足够的食物来提高“意愿值”。
    *   一名村民的背包中至少需要拥有以下数量之一的食物：3个面包、12个胡萝卜、12个马铃薯或12个甜菜根。
    *   当两名具备意愿且能互相看见的村民同时拥有充足食物，且附近有空余床位时，他们会互相投掷食物并产生幼年村民。

3.  **职业继承**
    *   幼年村民出生时没有职业。在他们成年后，会自动认领附近的空闲工作站点方块转职。

---

### 七、 治愈僵尸村民

通过治愈僵尸村民，玩家可以获得永久的交易折扣：

1.  **治愈步骤**
    *   **第一步：** 给僵尸村民施加“虚弱”效果。可以使用虚弱喷溅药水、滞留药水或虚弱之箭。
    *   **第二步：** 在虚弱效果消失前，对其使用一个金苹果。
    *   **第三步：** 等待转化。僵尸村民会开始剧烈抖动并发出红色粒子，整个过程通常需要3到5分钟。此期间建议将其围起来以防止阳光直射或受到其他生物攻击。

2.  **交易折扣规则（重要变更）**
    *   治愈成功后，该村民及其周围的部分村民会大幅降低交易价格。
    *   **注意：** 根据2026年及1.20.2版本后的规则，多次感染并治愈同一名村民，其交易折扣不再叠加。即“无限刷1绿宝石交易”的机制已被限制，折扣仅在第一次治愈时最为显著。

---

### 八、 安全防护：避雷针与女巫转化

村民在雷雨天气面临巨大的安全威胁，必须进行物理防护：

1.  **女巫转化机制**
    *   当闪电击中村民半径4格以内的区域时，该村民会立即转化为女巫。
    *   一旦转化为女巫，该过程是不可逆的（无法变回村民），且女巫会立即对玩家和剩余村民发起攻击。

2.  **避雷针的使用**
    *   **安装必要性：** 在村庄或村民交易中心必须安装避雷针。
    *   **安装位置：** 建议安装在村民活动区屋顶的上方，或者距离村民至少6格以外的高处。
    *   **工作原理：** 避雷针会将半径128格（Java版）或64格（基岩版）内的雷电吸引至自身。通过引导雷电，可以防止雷电误伤村民导致其集体“女巫化”。

3.  **屋顶材料建议**
    *   如果避雷针安装在木质建筑顶端，雷击可能引发火灾。建议避雷针底座使用石质或其他防燃方块。

---

### 九、 交易系统补充要点

1.  **经验增益：** 繁殖成功的村民在处于“有繁殖意愿”状态下与玩家交易，给予玩家的经验值会由普通的3-6点提升至8-11点。
2.  **失业村民：** 治愈后的僵尸村民如果之前有职业，治愈后会保留职业；如果是无职业村民，则需要重新提供工作站点。
3.  **傻子村民：** 傻子村民（绿袍）被治愈后依然是傻子，无法通过任何手段使其获得职业或进行交易。



## 指令

### 一、 命令语法符号说明

在阅读命令语法时，请参照以下符号含义：
*   **字面量（如 `gamemode`）**：必须按原样输入的单词。
*   **`<参数>`**：必须由你提供具体数值的部分。
*   **`[参数]`**：可选填的部分。
*   **`(a|b)`**：必须从a或b中选择一个输入。
*   **`~` 或 `^`**：坐标符号。`~`代表相对当前位置，`^`代表相对准星指向。

---

### 二、 核心命令详解（2026版）

#### 1. 基础管理与状态类
这类命令用于控制游戏环境和玩家基础属性。

| 命令           | 语法格式                         | 使用实例                       | 功能实现                                         |
| :------------- | :------------------------------- | :----------------------------- | :----------------------------------------------- |
| **gamemode**   | `gamemode <mode> [targets]`      | `/gamemode survival @a`        | 将所有玩家的游戏模式设为生存模式。               |
| **difficulty** | `difficulty <difficulty>`        | `/difficulty peaceful`         | 将世界难度立即设为和平，清除敌对生物。           |
| **time**       | `time (add\|query\|set) <value>` | `/time set 18000`              | 将时间设为午夜。                                 |
| **weather**    | `weather <type> [duration]`      | `/weather clear 1000`          | 设置天气为晴朗，并持续1000秒。                   |
| **gamerule**   | `gamerule <rule> [value]`        | `/gamerule keepInventory true` | 开启“死亡不掉落”规则。                           |
| **tick**       | `tick rate <value>`              | `/tick rate 40.0`              | 将游戏刻运行速度加倍（默认20），使游戏动作变快。 |

#### 2. 实体控制与传送类
用于精确操纵生物、玩家的位置及状态。

| 命令              | 语法格式                                          | 使用实例                                          | 功能实现                           |
| :---------------- | :------------------------------------------------ | :------------------------------------------------ | :--------------------------------- |
| **tp / teleport** | `tp <targets> <location>`                         | `/tp @p ~ ~10 ~`                                  | 将最近的玩家向上方传送10格。       |
| **summon**        | `summon <entity> [pos] [nbt]`                     | `/summon wolf ~ ~ ~ {Tame:1b}`                    | 在当前位置召唤一只已被驯服的狼。   |
| **kill**          | `kill <targets>`                                  | `/kill @e[type=item]`                             | 清理掉世界上所有掉落物实体。       |
| **effect**        | `effect give <targets> <effect> [seconds]`        | `/effect give @s invisibility 60`                 | 给自己施加60秒的隐身效果。         |
| **attribute**     | `attribute <target> <attribute> base set <value>` | `/attribute @s generic.attack_damage base set 10` | 将自己的基础攻击力永久修改为10点。 |
| **ride**          | `ride <targets> mount <target>`                   | `/ride @s mount @e[type=horse,limit=1]`           | 强制让自己骑上最近的一匹马。       |
| **swing**         | `swing <targets> <hand>`                          | `/swing @s off_hand`                              | 强制玩家播放副手挥动的动画。       |

#### 3. 物品与装备类
用于修改玩家背包和手中的物品属性。

| 命令        | 语法格式                                           | 使用实例                                                     | 功能实现                         |
| :---------- | :------------------------------------------------- | :----------------------------------------------------------- | :------------------------------- |
| **give**    | `give <targets> <item> [count]`                    | `/give @p diamond_block 64`                                  | 给最近的玩家一叠（64个）钻石块。 |
| **enchant** | `enchant <targets> <enchantment> [level]`          | `/enchant @s mending 1`                                      | 为手持物品添加经验修补魔咒。     |
| **clear**   | `clear <targets> [item]`                           | `/clear @a rotten_flesh`                                     | 清空所有玩家背包里的腐肉。       |
| **item**    | `item replace entity <targets> <slot> with <item>` | `/item replace entity @s weapon.mainhand with netherite_axe` | 强制将主手物品替换为下界合金斧。 |
| **loot**    | `loot give @s fish minecraft:fishing/fishing_rod`  | `/loot give @s fish ~ ~ ~`                                   | 模拟一次钓鱼掉落并将物品给玩家。 |

#### 4. 建筑与环境修改类
用于大范围地修改地图方块。

| 命令          | 语法格式                                          | 使用实例                              | 功能实现                                   |
| :------------ | :------------------------------------------------ | :------------------------------------ | :----------------------------------------- |
| **setblock**  | `setblock <pos> <block> [destroy\|keep\|replace]` | `/setblock ~ ~-1 ~ diamond_ore`       | 将脚下的方块直接替换为钻石矿石。           |
| **fill**      | `fill <from> <to> <block>`                        | `/fill ~-1 ~-1 ~-1 ~1 ~1 ~1 tnt`      | 在玩家周围生成一个3x3x3的TNT方块组。       |
| **clone**     | `clone <begin> <end> <destination>`               | `/clone 0 64 0 5 70 5 ~ ~ ~`          | 将坐标(0,64,0)处的建筑复制到玩家当前位置。 |
| **locate**    | `locate (structure\|biome) <id>`                  | `/locate structure fortress`          | 寻找最近的下界要塞并反馈坐标。             |
| **fillbiome** | `fillbiome <from> <to> <biome>`                   | `/fillbiome ~-5 ~ ~-5 ~5 ~ ~5 desert` | 将指定区域的生物群系属性改为沙漠。         |

#### 5. 逻辑、数据与2026新特性（进阶）
用于自动化控制、视觉效果和新加入的路径系统。

| 命令           | 语法格式                                      | 使用实例                                          | 功能实现                                         |
| :------------- | :-------------------------------------------- | :------------------------------------------------ | :----------------------------------------------- |
| **execute**    | `execute as <targets> at @s run <command>`    | `/execute as @a at @s run setblock ~ ~-1 ~ glass` | 让所有玩家在移动时脚下不断生成玻璃。             |
| **scoreboard** | `scoreboard players add <target> <obj> <val>` | `/scoreboard players add @s money 100`            | 给玩家名为“money”的计分板数值增加100点。         |
| **tag**        | `tag <targets> add <name>`                    | `/tag @e[type=creeper] add friendly`              | 给所有苦力怕添加“friendly”标签以供筛选。         |
| **data**       | `data get entity @s`                          | `/data get entity @s Health`                      | 查询并显示当前玩家的精确健康值数据（Java版）。   |
| **posteffect** | `posteffect add <targets> <id>`               | `/posteffect add @s minecraft:bits`               | 在玩家屏幕上开启类似像素风或电子化的后处理滤镜。 |
| **waypoint**   | `waypoint add <name> <pos>`                   | `/waypoint add base ~ ~ ~`                        | 在当前位置添加一个名为“base”的常驻导航路径点。   |
| **dialog**     | `dialog open <targets> <id>`                  | `/dialog open @a quest_info`                      | 向全服玩家弹出一个预设好的NPC剧情对话框。        |
| **random**     | `random value <range>`                        | `/random value 1..100`                            | 在1到100之间抽取一个随机数并显示结果。           |

---

### 三、 目标选择器（常用参数）
命令中的 `<targets>` 通常使用以下选择器：
*   **@p**：最近的玩家。
*   **@a**：所有玩家。
*   **@r**：随机玩家。
*   **@e**：所有实体（包括掉落物和生物）。
*   **@s**：执行命令的实体或玩家自己。
*   **@e[type=zombie]**：通过属性筛选，例如“所有僵尸”。

### 四、 2026版特别提示
1.  **路径点系统**：通过 `/waypoint` 创建的标记会直接显示在玩家的UI或定位栏中，极大地便利了生存导航。
2.  **执行机制**：`/execute` 现在支持更多复合逻辑（如 `if score` 或 `if dimension`），是制作复杂小游戏和自动化机器的核心。
3.  **时间控制**：`/tick` 指令不仅可以改变速率，还可以使用 `tick freeze` 冻结物理世界，而玩家依然可以自由行动，常用于调试或拍摄。
